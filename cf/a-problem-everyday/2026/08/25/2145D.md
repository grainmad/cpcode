## problem


                                    长度为 $n$ 的排列是一个包含 $n$ 个整数的数组，其中每个 $1$ 到 $n$ 的数字恰好出现一次。对于一个排列 $p$，如果存在一对下标 $(i, j)$，满足 $i < j$ 且 $p_i > p_j$，则称 $(i, j)$ 是排列 $p$ 的一个逆序对。

对于排列 $p$，我们定义它的“逆序区间值”是：所有包含至少一个逆序对的子区间的数量。形式化地说，这等价于满足条件的整数对 $(l, r)$ 的个数（$1 \leq l < r \leq n$），使得区间 $[l, r]$ 存在一对下标 $(i, j)$ 满足 $l \leq i < j \leq r$ 且 $p_i > p_j$。

例如，对于排列 $[3, 1, 4, 2]$，其逆序区间值为 $5$。

现给定两个整数 $n$ 和 $k$。请你构造一个长度为 $n$ 的排列，使其逆序区间值恰好等于 $k$。
                            

## solution


**正难则反**：先数"干净区间"。子区间不含逆序对 $\iff$ 严格递增，令 $k' = \binom{n}{2} - k$，改为构造恰有 $k'$ 个递增子区间的排列。

**关键观察：数量只由极大递增段决定。** 递增子区间必然完整落在某个极大递增段内，长为 $t$ 的段贡献 $\binom{t}{2}$ 个，跨段的区间必含逆序。于是问题化为：把 $n$ 划分成若干段长 $t_1, t_2, \dots$，使

$$\sum_i \binom{t_i}{2} = k'$$

**可行性 dp**：$f_{i,j}$ 表示"$i$ 个元素划分成若干段、递增子区间数恰为 $j$"是否可行，转移枚举下一段长 $t$：$f_{i+t,\ j + t(t-1)/2} \mid= f_{i,j}$。若 $f_{n, k'}$ 为假则无解，输出 $0$（$k$ 并非全部可达，如 $n=3,\ k=1$）。

**构造**：从 $(n, k')$ 沿 dp 回溯出段长序列（段序无关，代码里倒序取也无妨）；把值域从大到小分段分配——最大的 $t$ 个数升序放第一个输出段，次大的放第二段……跨段任意两数都构成逆序，故极大递增段恰为所给段，递增子区间数 $= \sum_i \binom{t_i}{2} = k'$，逆序区间值即 $k$。

复杂度：状态 $O(n \cdot \binom{n}{2})$、每状态 $O(n)$ 条转移，$n \le 30$ 时逐测重算也仅约 $4 \times 10^5$ 次操作；官方 Python 标程逐测算 dp 会 TLE（需全局预计算一次），C++ 则无碍。
