## problem


                                    [ALTER EGO - Yuta Imai vs Qlarabelle](https://www.youtube.com/watch?v=LJEqM7pvClA)

这是一道交互题。

存在两个隐藏的非负整数 $x$ 和 $y$（$0 \leq x, y < 2^{30}$）。你最多可以提出 2 次以下形式的询问：

- 选择一个非负整数 $n$（$0 \leq n < 2^{30}$）。评测系统将返回 $(n \mathbin{|} x) + (n \mathbin{|} y)$ 的值，其中 $|$ 表示[按位或运算](https://en.wikipedia.org/wiki/Bitwise_operation#OR)。

此后，评测系统将给出另一个非负整数 $m$（$0 \leq m < 2^{30}$）。你必须正确回答 $(m \mathbin{|} x) + (m \mathbin{|} y)$ 的值。
                            

## solution


设 $c_i = x_i + y_i \in \{0,1,2\}$ 为第 $i$ 位上 $x,y$ 置位个数之和。$(m|x)+(m|y)$ 在第 $i$ 位的贡献是 $2\cdot 2^i$（$m_i=1$）或 $2^i c_i$（$m_i=0$），**最终答案只依赖每个 $c_i$，与 $x,y$ 各自的分布无关**。问题化为：用两次询问定出全部 30 个 $c_i$。

一次询问 $n$ 的返回值按位分解为

$$B(n) = (n|x)+(n|y) = 2n + \sum_{i:\,n_i=0} 2^i\, c_i,$$

即 $B(n)-2n$ 恰好是 $n$ 的**零 bit 位**上各 $c_i$ 的加权和。取互补的隔位掩码（隔 2 位是让每个数字 $c_i \le 2$ 落在无进位的"伪四进制"位上）：

- 问 $n_{odd} = (1010\cdots10)_2 = 715827882$，则 $S_{even} = B(n_{odd}) - 2n_{odd} = \sum_{k=0}^{14} 4^k\, c_{2k}$。每位数字 $\le 2 < 4$，从低到高逐位 $S \bmod 4$ 即可无损解出每个 $c_{2k}$（映射单射，无进位歧义）；
- 问 $n_{even} = (0101\cdots01)_2 = 357913941$，同理 $S_{odd}/2 = \sum_{k=0}^{14} 4^k\, c_{2k+1}$，解出每个 $c_{2k+1}$。

打印 `!` 读入 $m$ 后输出

$$\mathrm{ans} \;=\; 2m + \sum_{i:\,m_i=0} 2^i\, c_i \;=\; 2m + \bigl(S_{even}+S_{odd}\bigr) - \sum_{i:\,m_i=1} 2^i\, c_i .$$

复杂度每组 $O(30)$。交互格式注意：询问只打印 $n$ 本身（无前缀）；问完打印 `!` 才能读到 $m$；每次输出后 flush。
