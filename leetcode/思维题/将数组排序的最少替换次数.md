## 题目

[2450. 将数组排序的最少替换次数](https://leetcode.cn/problems/minimum-replacements-to-sort-the-array/)


---


给你一个下标从 **0** 开始的整数数组 `nums` 。每次操作中，你可以将数组中任何一个元素替换为 **任意两个** 和为该元素的数字。

	- 比方说，`nums = [5,6,7]` 。一次操作中，我们可以将 `nums[1]` 替换成 `2` 和 `4` ，将 `nums` 转变成 `[5,2,4,7]` 。

请你执行上述操作，将数组变成元素按 **非递减** 顺序排列的数组，并返回所需的最少操作次数。

 

**示例 1：**

**输入：**nums = [3,9,3]
**输出：**2
**解释：**以下是将数组变成非递减顺序的步骤：
- [3,9,3] ，将9 变成 3 和 6 ，得到数组 [3,3,6,3] 
- [3,3,6,3] ，将 6 变成 3 和 3 ，得到数组 [3,3,3,3,3] 
总共需要 2 步将数组变成非递减有序，所以我们返回 2 。

**示例 2：**

**输入：**nums = [1,2,3,4,5]
**输出：**0
**解释：**数组已经是非递减顺序，所以我们返回 0 。

 

**提示：**

	- `1 <= nums.length <= 10^5^`

	- `1 <= nums[i] <= 10^9^`


## 题解


### 思路

现在需要解决这样一个问题：
有顺序的三个数$a,b,c$
需要将$b$拆分，拆分后每个数都要不大于$c$，然后每个数又要尽可能大，直观的感觉就是将$b$拆分成$\lceil \frac{b}{c} \rceil$个数，如果没有余数，那么每个数都是拆分成了$c$；此时如果有余数就是$c\%b$，这并不能保证$c\%b$尽可能大，虽然其他拆分的数都是$c$。我们可以让其余的一些数贡献一部分到这个余数上，实际上这个余数可以上升到$c-1$，其余的数也至多只要减少$1$，为什么会这样？因为$\lceil \frac{b}{c-1} \rceil \ge \lceil \frac{b}{c} \rceil$。每个数都为这个余数贡献1甚至会有多余。另外也可以证明$\lfloor\frac{b}{c}\rfloor+b\%c\ge c-1$
$\lfloor\frac{b}{c}\rfloor + b - \lfloor\frac{b}{c}\rfloor * c \ge c-1$
$b - \lfloor\frac{b}{c}\rfloor * (c-1) \ge c-1$
$\lfloor\frac{b}{c-1}\rfloor - \lfloor\frac{b}{c}\rfloor  \ge 1$
由于是整数运算$\lfloor\frac{b}{c-1}\rfloor - \lfloor\frac{b}{c}\rfloor  > 0$
分子不变分母越小越大。

如果`nums[i]>nums[i+1]`, 此时至少要拆$\lceil \frac{nums[i]}{nums[i+1]} \rceil -1$次。
又要使得拆成的$\lceil \frac{nums[i]}{nums[i+1]} \rceil$个数尽可能大，所以拆成的最小值最大是$\lfloor \frac{nums[i]}{\lceil \frac{nums[i]}{nums[i+1]} \rceil} \rfloor$


### 代码


```cpp
class Solution {
public:
    long long minimumReplacement(vector<int>& nums) {
        long long ans = 0;
        int n = nums.size();
        for (int i=n-2; i>=0; i--) {
            int x = (nums[i]+nums[i+1]-1)/nums[i+1];
            ans += x-1;
            nums[i] = nums[i]/x;
        }
        return ans;
    }
};
```
