## 题目

[1478. 最多可以参加的会议数目](https://leetcode.cn/problems/maximum-number-of-events-that-can-be-attended/)


---


给你一个数组 `events`，其中 `events[i] = [startDay_i_, endDay_i_]` ，表示会议 `i` 开始于 `startDay_i_` ，结束于 `endDay_i_` 。

你可以在满足 `startDay_i_ <= d <= endDay_i_`_ _中的任意一天 `d` 参加会议 `i` 。在任意一天 `d` 中只能参加一场会议。

请你返回你可以参加的 **最大 **会议数目。

 

**示例 1：**

[]

**输入：**events = [[1,2],[2,3],[3,4]]
**输出：**3
**解释：**你可以参加所有的三个会议。
安排会议的一种方案如上图。
第 1 天参加第一个会议。
第 2 天参加第二个会议。
第 3 天参加第三个会议。

**示例 2：**

**输入：**events= [[1,2],[2,3],[3,4],[1,2]]
**输出：**4

 

**提示：**​​​​​​

	- `1 <= events.length <= 10^5^`

	- `events[i].length == 2`

	- `1 <= startDay_i_ <= endDay_i_ <= 10^5^`


## 题解


### 思路

枚举每一天，将当天开始的会议的结束加入到小根堆。然后移除堆内结束时间小于当天的会议。最后选择堆内结束时间最早的。


### 代码


```cpp
class Solution {
public:
    #define N 100005
    vector<int> h[N]; // h[i] 第i天开始的会议集合
    int maxEvents(vector<vector<int>>& events) {
        int n = events.size();
        for (int i=0; i<n; i++) {
            h[events[i][0]].push_back(i);
        }
        int ans = 0;
        priority_queue<int, vector<int>, greater<int>> que;
        for (int i=0; i<N; i++) {
            for (int j:h[i]) que.push(events[j][1]);//将第i天开始的会议的结束时间加入到优先队列
            while (que.size() && que.top()<i) que.pop();//移除结束时间小于当天的会议
            if (que.size()) que.pop(), ans++; //当天选择结束时间最早的会议
        }
        return ans;
    }
};
```
