## 题目

[2363. 转角路径的乘积中最多能有几个尾随零](https://leetcode.cn/problems/maximum-trailing-zeros-in-a-cornered-path/)


---


给你一个二维整数数组 `grid` ，大小为 `m x n`，其中每个单元格都含一个正整数。

**转角路径** 定义为：包含至多一个弯的一组相邻单元。具体而言，路径应该完全 **向水平方向** 或者 **向竖直方向** 移动过弯（如果存在弯），而不能访问之前访问过的单元格。在过弯之后，路径应当完全朝 **另一个** 方向行进：如果之前是向水平方向，那么就应该变为向竖直方向；反之亦然。当然，同样不能访问之前已经访问过的单元格。

一条路径的 **乘积** 定义为：路径上所有值的乘积。

请你从 `grid` 中找出一条乘积中尾随零数目最多的转角路径，并返回该路径中尾随零的数目。

注意：

	- **水平** 移动是指向左或右移动。

	- **竖直 **移动是指向上或下移动。

 

**示例 1：**

[]

**输入：**grid = [[23,17,15,3,20],[8,1,20,27,11],[9,4,6,2,21],[40,9,1,10,6],[22,7,4,5,3]]
**输出：**3
**解释：**左侧的图展示了一条有效的转角路径。
其乘积为 15 * 20 * 6 * 1 * 10 = 18000 ，共计 3 个尾随零。
可以证明在这条转角路径的乘积中尾随零数目最多。

中间的图不是一条有效的转角路径，因为它有不止一个弯。
右侧的图也不是一条有效的转角路径，因为它需要重复访问已经访问过的单元格。

**示例 2：**

[]

**输入：**grid = [[4,3,2],[7,6,1],[8,8,8]]
**输出：**0
**解释：**网格如上图所示。
不存在乘积含尾随零的转角路径。

 

**提示：**

	- `m == grid.length`

	- `n == grid[i].length`

	- `1 <= m, n <= 10^5^`

	- `1 <= m * n <= 10^5^`

	- `1 <= grid[i][j] <= 1000`


## 题解


### 思路

2和5**

注意到可以维护横向和纵向的前缀和，通过前缀和之差可以O(1)时间复杂度求区间的乘积，但是直接求乘积会溢出。其实尾数0的个数跟质因子2和5的个数有关，所以前缀和只需要统计2和5因子出现的次数即可。当有一个2和一个5相乘就会产生一个0，所以2和5出现的最少个数便是0的个数。


### 代码


```cpp
class Solution {
public:
    int maxTrailingZeros(vector<vector<int>>& grid) {
        int n = grid.size(), m = grid[0].size(), ans = 0;
        vector<vector<int>> 
        r2(n, vector<int>(m+1, 0)), 
        r5(n, vector<int>(m+1, 0)), 
        c2(m, vector<int>(n+1, 0)),
        c5(m, vector<int>(n+1, 0));
        for (int i=0; i<n; i++) {
            for (int j=1; j<=m; j++) {
                r2[i][j] = r2[i][j-1];
                r5[i][j] = r5[i][j-1];
                int u = grid[i][j-1];
                while (u%2 == 0) {
                    r2[i][j]++;
                    u/=2;
                }
                while (u%5 == 0) {
                    r5[i][j]++;
                    u/=5;
                }
            }
            ans = max(ans, min(r2[i][m], r5[i][m]));
        }
        for (int i=0; i<m; i++) {
            for (int j=1; j<=n; j++) {
                c2[i][j] = c2[i][j-1];
                c5[i][j] = c5[i][j-1];
                int u = grid[j-1][i];
                while (u%2 == 0) {
                    c2[i][j]++;
                    u/=2;
                }
                while (u%5 == 0) {
                    c5[i][j]++;
                    u/=5;
                }
            }
            ans = max(ans, min(c2[i][n], c5[i][n]));
        }
        for (int i=0; i<n; i++) {
            for (int j=0; j<m; j++) {
                int _2 = r2[i][j+1]-r2[i][j], _5 = r5[i][j+1]-r5[i][j];
                int d2[4] = {r2[i][j], c2[j][i], r2[i][m]-r2[i][j+1], c2[j][n]-c2[j][i+1]};
                int d5[4] = {r5[i][j], c5[j][i], r5[i][m]-r5[i][j+1], c5[j][n]-c5[j][i+1]};
                for (int k=0; k<4; k++) {
                    ans = max(ans, min(d2[k]+d2[(k+1)%4]+_2, d5[k]+d5[(k+1)%4]+_5));
                }
            }
        }
        return ans;
    }
};
```
