## 题目

[1145. 元素和为目标值的子矩阵数量](https://leetcode.cn/problems/number-of-submatrices-that-sum-to-target/)


---


给出矩阵 `matrix` 和目标值 `target`，返回元素总和等于目标值的非空子矩阵的数量。

子矩阵 `x1, y1, x2, y2` 是满足 `x1 <= x <= x2` 且 `y1 <= y <= y2` 的所有单元 `matrix[x][y]` 的集合。

如果 `(x1, y1, x2, y2)` 和 `(x1', y1', x2', y2')` 两个子矩阵中部分坐标不同（如：`x1 != x1'`），那么这两个子矩阵也不同。

 

**示例 1：**

[]

**输入：**matrix = [[0,1,0],[1,1,1],[0,1,0]], target = 0
**输出：**4
**解释：**四个只含 0 的 1x1 子矩阵。

**示例 2：**

**输入：**matrix = [[1,-1],[-1,1]], target = 0
**输出：**5
**解释：**两个 1x2 子矩阵，加上两个 2x1 子矩阵，再加上一个 2x2 子矩阵。

**示例 3：**

**输入：**matrix = [[904]], target = 0
**输出：**0

 

**提示：**

	- `1 <= matrix.length <= 100`

	- `1 <= matrix[0].length <= 100`

	- `-1000 <= matrix[i][j] <= 1000`

	- `-10^8 <= target <= 10^8`


## 题解


### 思路

可以四重for循环过，时间复杂度$O(n^2m^2)$
转换560题一维情况
计算每列前缀和，枚举子矩阵上下界，将每行中每列之和合并为一维数组。合并可以通过前缀和$O(1)$求区间和做到。


### 代码


```cpp
class Solution {
public:
    int numSubmatrixSumTarget(vector<vector<int>>& mat, int ta) {
        int n = mat.size(), m = mat[0].size();
        vector<vector<long>> rp(n, vector<long>(m+1));
        for (int i=0; i<n; i++) {
            for (int j=1; j<=m; j++) {
                rp[i][j] = rp[i][j-1]+mat[i][j-1];
            }
        }
        int ans = 0;
        for (int r=1; r<=m; r++) {
            for (int l=0; l<r; l++) {
                unordered_map<long, int> mp;
                mp[0] = 1;
                long p = 0;
                for (int i=0; i<n; i++) {
                    p += rp[i][r]-rp[i][l];
                    if (mp.count(p-ta)) ans += mp[p-ta];
                    mp[p]++;
                }
            }
        }
        return ans;
    }
};
```
