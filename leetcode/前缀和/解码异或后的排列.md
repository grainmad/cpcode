## 题目

[1835. 解码异或后的排列](https://leetcode.cn/problems/decode-xored-permutation/)


---


给你一个整数数组 `perm` ，它是前 `n` 个正整数的排列，且 `n` 是个 **奇数** 。

它被加密成另一个长度为 `n - 1` 的整数数组 `encoded` ，满足 `encoded[i] = perm[i] XOR perm[i + 1]` 。比方说，如果 `perm = [1,3,2]` ，那么 `encoded = [2,1]` 。

给你 `encoded` 数组，请你返回原始数组 `perm` 。题目保证答案存在且唯一。

 

**示例 1：**

**输入：**encoded = [3,1]
**输出：**[1,2,3]
**解释：**如果 perm = [1,2,3] ，那么 encoded = [1 XOR 2,2 XOR 3] = [3,1]

**示例 2：**

**输入：**encoded = [6,5,4,6]
**输出：**[2,4,1,5,3]

 

**提示：**

	- `3 <= n < 10^5^`

	- `n` 是奇数。

	- `encoded.length == n - 1`


## 题解


### 思路

异或性质**

$encoded$的后缀异或和分别代表着$n-1$个数与`perm[n]`的异或和。我们只需要知道`perm[n]`就可以知道其他$n-1$个数了
由于$n-1$为偶数，所以将后缀异或和求异或和可得除`perm[n]`的$n-1$个数的异或和$p$，事先将$1$到$n$的异或和求出$q$，可得`perm[n] = p^q`


### 代码


```cpp
class Solution {
public:
    vector<int> decode(vector<int>& encoded) {
        int n = encoded.size();
        int s = 0;
        for (int i=1; i<=n+1; i++) {
            s ^= i;
        }
        for (int i=n-2; i>=0; i--) {
            encoded[i] ^= encoded[i+1];
        }
        int la = 0;
        for (int i:encoded) {
            la ^= i;
        }
        s ^= la;
        for (auto& i:encoded) {
            i ^= s;
        }
        encoded.push_back(s);
        return encoded;
    }
};
```
