## 题目

[32. 最长有效括号](https://leetcode.cn/problems/longest-valid-parentheses/)


---


给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号 子串 的长度。

左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 `"(()())"`。

 

**示例 1：**

**输入：**s = "(()"
**输出：**2
**解释：**最长有效括号子串是 "()"

**示例 2：**

**输入：**s = ")()())"
**输出：**4
**解释：**最长有效括号子串是 "()()"

**示例 3：**

**输入：**s = ""
**输出：**0

 

**提示：**

	- `0 <= s.length <= 3 * 10^4^`

	- `s[i]` 为 `'('` 或 `')'`


## 题解


### 思路

dp 单调栈**
- dp
    
    若`s[i]=‘)’`, `dp[i]`是以`i`结尾的最长连续有效括号的左端下标
    若`s[i]=‘(’`, `dp[i]=-1`
    
    若`s[i]=')', s[i-1]='('`, `s[i-1]`与`s[i]`可组成合法串，所以`dp[i]=i-1`,此时若`s[i-2]=’)‘`且`dp[i-2]`则合法串可以向左延申`dp[i]=dp[i-2]`;
    
    若`s[i]=')', s[i-1]=')'`, `dp[i-1]`存在的情况下，只要`s[dp[i-1]-1]='('`便可与`s[i]`可组成合法串，所以`dp[i]=dp[i-1]-1`, 和上一种情况一样，此时的合法串可能不是最长的，若左边还存再一个合法串则dp需要继续向左延申。
    
    
    
- 单调栈


### 代码


```cpp
    class Solution {
    public:
        int dp[30004];
        int longestValidParentheses(string s) {
            s = ")"+s;
            int ans = 0;
            memset(dp, -1, sizeof(dp));
            for (int i=1; i<s.size(); i++) {
                if ('(' == s[i]) continue;
                if (s[i-1] == '(') dp[i] = i-1;
                else if (dp[i-1] != -1 && s[dp[i-1]-1] == '(') dp[i] = dp[i-1]-1;
                if (dp[i] == -1) continue;
                int t = dp[i]-1;
                if (t == -1) continue;
                if (dp[t] != -1) dp[i] = dp[t];
                ans = max(ans, i-dp[i]+1);
            }
            // for (int i=0; i<s.size(); i++) cout << dp[i] << "  " << endl;
            return ans;
        }
    };
    ```


```cpp
    class Solution {
    public:
        int longestValidParentheses(string s) {
            vector<int> ans(1, 0);
            vector<char> st;
            for (char i:s) {
                if (i == '(') {
                    st.push_back(i);
                    ans.push_back(0);
                } else {
                    if (!st.empty()) {
                        st.pop_back();
                        int t = ans.back(); ans.pop_back();
                        t+=2;
                        ans.back()+=t;
                    } else ans.push_back(0);
                }
            }
            int rt = 0;
            for (int i : ans) rt = max(rt, i);
            return rt;
        }
    };
    ```
