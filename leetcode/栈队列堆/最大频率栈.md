## 题目

[931. 最大频率栈](https://leetcode.cn/problems/maximum-frequency-stack/)


---


设计一个类似堆栈的数据结构，将元素推入堆栈，并从堆栈中弹出**出现频率**最高的元素。

实现 `FreqStack` 类:

	- `FreqStack()` 构造一个空的堆栈。

	- `void push(int val)` 将一个整数 `val` 压入栈顶。

	- `int pop()` 删除并返回堆栈中出现频率最高的元素。
	
		- 如果出现频率最高的元素不只一个，则移除并返回最接近栈顶的元素。

	
	

 

**示例 1：**

**输入：**
["FreqStack","push","push","push","push","push","push","pop","pop","pop","pop"],
[[],[5],[7],[5],[7],[4],[5],[],[],[],[]]
**输出：**[null,null,null,null,null,null,null,5,7,5,4]
**解释：**
FreqStack = new FreqStack();
freqStack.push (5);//堆栈为 [5]
freqStack.push (7);//堆栈是 [5,7]
freqStack.push (5);//堆栈是 [5,7,5]
freqStack.push (7);//堆栈是 [5,7,5,7]
freqStack.push (4);//堆栈是 [5,7,5,7,4]
freqStack.push (5);//堆栈是 [5,7,5,7,4,5]
freqStack.pop ();//返回 5 ，因为 5 出现频率最高。堆栈变成 [5,7,5,7,4]。
freqStack.pop ();//返回 7 ，因为 5 和 7 出现频率最高，但7最接近顶部。堆栈变成 [5,7,5,4]。
freqStack.pop ();//返回 5 ，因为 5 出现频率最高。堆栈变成 [5,7,4]。
freqStack.pop ();//返回 4 ，因为 4, 5 和 7 出现频率最高，但 4 是最接近顶部的。堆栈变成 [5,7]。

 

**提示：**

	- `0 <= val <= 10^9^`

	- `push` 和 `pop` 的操作数不大于 `2 * 10^4^`。

	- 输入保证在调用 `pop` 之前堆栈中至少有一个元素。


## 题解


### 思路

栈 堆**

优先队列支持取出最大频率的数，但是不支持修改某个数的频率。
对于要修改的数，直接新加入同一个数但不同的频率。
然后记录某个数当前的真实频率。当优先队列拿出的数与真实频率不同，说明这个数据是过时的数据。
这个题不仅要比较数的频率还要比较数离栈顶的位置。

**solution1**

用优先队列存储 {频率，位置，值}。
优先弹出频率大的，频率相同则位置大的。
这里的位置只增不减，所以每个位置都会不同。
对于相同的值，可能存在不同频率，每个值当前的频率便是队列中最大的频率，我们需要维护每个值的当前频率，因为再插入某个值需要增长频率。

**solution2**

将栈按照频次分组
`st[i]`存储着频次为i的元素。对于相同频次的元素是后进先出的。


### 代码


```cpp
class FreqStack {
public:
    struct Node {
        int cnt, pos, val;
        bool operator<(const Node& o) const {
            if (cnt == o.cnt) return pos<o.pos;
            return cnt<o.cnt;
        }
    };
    int sz;
    map<int,int> mp;
    priority_queue<Node> que;
    FreqStack() {

    }
    
    void push(int val) {
        mp[val]++;
        que.push({mp[val], sz++, val});
    }
    
    int pop() {
        auto t = que.top(); que.pop();
        mp[t.val]--;
        return t.val;
    }
};

class FreqStack {
public:
    unordered_map<int,int> mp;
    vector<stack<int>> st;
    FreqStack():st(1) {
    }
    
    void push(int val) {
        if (++mp[val] == st.size()) st.push_back({});
        st[mp[val]].push(val);
    }
    
    int pop() {
        int rt = st.back().top();
        st.back().pop();
        if (st.back().empty()) st.pop_back();
        mp[rt]--;
        return rt;
    }
};

/**
 * Your FreqStack object will be instantiated and called as such:
 * FreqStack* obj = new FreqStack();
 * obj->push(val);
 * int param_2 = obj->pop();
 */
```
