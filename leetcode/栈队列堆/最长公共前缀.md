## 题目

[14. 最长公共前缀](https://leetcode.cn/problems/longest-common-prefix/)


---


编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 `""`。

 

示例 1：

**输入：**strs = ["flower","flow","flight"]
**输出：**"fl"

示例 2：

**输入：**strs = ["dog","racecar","car"]
**输出：**""
**解释：**输入不存在公共前缀。

 

**提示：**

	- `1 <= strs.length <= 200`

	- `0 <= strs[i].length <= 200`

	- `strs[i]` 如果非空，则仅由小写英文字母组成

### 代码


```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        if (strs.size() == 0) return "";
        string rt = "";
        auto sz = strs[0].size();
        for (auto i : strs) {
            sz = min(sz, i.size());
        }
        for (int i=0; i<sz; i++) {
            bool flag = true;
            for (auto j : strs) {
                if (j[i] != strs[0][i]) flag = false;
            }
            if (flag) rt.push_back(strs[0][i]);
            else return rt;
        }
        return rt;
    }
};
```
