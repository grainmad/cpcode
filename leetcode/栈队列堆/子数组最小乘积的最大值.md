## 题目

[1985. 子数组最小乘积的最大值](https://leetcode.cn/problems/maximum-subarray-min-product/)


---


一个数组的 **最小乘积** 定义为这个数组中 **最小值** **乘以 **数组的 **和** 。

	- 比方说，数组 `[3,2,5]` （最小值是 `2`）的最小乘积为 `2 * (3+2+5) = 2 * 10 = 20` 。

给你一个正整数数组 `nums` ，请你返回 `nums` 任意 **非空子数组** 的**最小乘积** 的 **最大值** 。由于答案可能很大，请你返回答案对  `10^9^ + 7` **取余 **的结果。

请注意，最小乘积的最大值考虑的是取余操作 **之前** 的结果。题目保证最小乘积的最大值在 **不取余** 的情况下可以用 **64 位有符号整数** 保存。

**子数组** 定义为一个数组的 **连续** 部分。

 

**示例 1：**

**输入：**nums = [1,**2,3,2**]
**输出：**14
**解释：**最小乘积的最大值由子数组 [2,3,2] （最小值是 2）得到。
2 * (2+3+2) = 2 * 7 = 14 。

**示例 2：**

**输入：**nums = [2,**3,3**,1,2]
**输出：**18
**解释：**最小乘积的最大值由子数组 [3,3] （最小值是 3）得到。
3 * (3+3) = 3 * 6 = 18 。

**示例 3：**

**输入：**nums = [3,1,**5,6,4**,2]
**输出：**60
**解释：**最小乘积的最大值由子数组 [5,6,4] （最小值是 4）得到。
4 * (5+6+4) = 4 * 15 = 60 。

 

**提示：**

	- `1 <= nums.length <= 10^5^`

	- `1 <= nums[i] <= 10^7^`


## 题解


### 思路

单调栈寻找子数组边界**

对于一个数`nums[i]`，如果`nums[i]`作为数组的最小值那么我们要在`nums[i]`左侧找到最多连续的大于等于`nums[i]`的数，右侧找到最多连续的大于等于`nums[i]`的数，这样保证了数组和尽可能的大。
利用单调栈可以预处理出每个数`nums[i]`左侧最近的小于`nums[i]`的位置j，即`l[i] = j`。
利用单调栈可以预处理出每个数`nums[i]`右侧最近的小于`nums[i]`的位置`j`，即`r[i] = j`。
再求出前缀和`p[i] = sum(nums[0....i-1])`。
对于每个`nums[i]`作为数组中的最小值的**最小乘积**为`nums[i]*(p[r[i])-p[l[i]+1))`


### 代码


```cpp
class Solution {
public:
    int maxSumMinProduct(vector<int>& nums) {
        int n = nums.size();
        vector<int> l(n, -1), r(n, n);
        vector<long> p(n+1, 0);
        for (int i=1; i<=n; i++) {
            p[i] = p[i-1]+nums[i-1];
        }
        vector<int> st;
        for (int i=0; i<n; i++) {
            while (!st.empty() && nums[st.back()] >= nums[i]) st.pop_back();
            if (!st.empty()) l[i] = st.back();
            st.push_back(i);
        }
        while (st.size()) st.pop_back();
        for (int i=0; i<n; i++) {
            while (!st.empty() && nums[st.back()] > nums[i]) {
                r[st.back()] = i;
                st.pop_back();
            }
            st.push_back(i);
        }
        long ans = 0;
        for (int i=0; i<n; i++ ) {
            ans = max(ans, (p[r[i]]-p[l[i]+1])*nums[i]);
        }
        return ans%(int(1e9+7));
    }
};
```
