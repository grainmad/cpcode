## 题目

[989. 按公因数计算最大组件大小](https://leetcode.cn/problems/largest-component-size-by-common-factor/)


---


给定一个由不同正整数的组成的非空数组 `nums` ，考虑下面的图：

	- 有 `nums.length` 个节点，按从 `nums[0]` 到 `nums[nums.length - 1]` 标记；

	- 只有当 `nums[i]` 和 `nums[j]` 共用一个大于 1 的公因数时，`nums[i]` 和 `nums[j]`之间才有一条边。

返回 *图中最大连通组件的大小* 。

 

**示例 1：**

**输入：**nums = [4,6,15,35]
**输出：**4

**示例 2：**

**输入：**nums = [20,50,9,63]
**输出：**2

**示例 3：**

**输入：**nums = [2,3,6,7,4,12,21,39]
**输出：**8

 

**提示：**

	- `1 <= nums.length <= 2 * 10^4^`

	- `1 <= nums[i] <= 10^5^`

	- `nums` 中所有值都 **不同**


## 题解


### 思路

并查集 数论**

**solution 1**
类似筛选法，枚举从2到N的每个i的倍数，然后用并查集将i的倍数全部联合，最后并查集最大的一个集合的大小是答案。时间复杂度$O(N/2+N/3+N/4+...N/N)$
**solution 2**
直接求nums中每个数i的因数，并用并查集联合i和这些因数。
维护最大的集合中真正存在在nums中的个数。


### 代码


```cpp
class Solution { // solution 1
public:
    #define N 100005
    int st[N];
    int cnt[N];
    int ufind(int x) {
        return st[x]<0?x:st[x] = ufind(st[x]);
    }
    int largestComponentSize(vector<int>& nums) {
        memset(st, -1, sizeof(st));
        for (int i:nums) {
            cnt[i] = 1;
        }
        sort(nums.begin(), nums.end());
        for (int i=2; i<N; i++) {
            int fx = -1;
            for (int j=i; j<N; j+=i) {
                if (cnt[j]) {
                    if (fx == -1) fx = ufind(j);
                    else {
                        int fy = ufind(j);
                        if (fx != fy) {
                            st[fx] += st[fy];
                            st[fy] = fx;
                        }
                    }
                }
            }
        }
        int ans = 1;
        for (int i=0; i<N; i++) {
            if (cnt[i]) ans = max(ans, -st[i]);
        }
        return ans;
    }
};

class Solution {//solution 2
public:
    int cnt[100005];
    int st[100005];
    int ufind(int x) {
        return st[x]<0?x:st[x] = ufind(st[x]);
    }
    int largestComponentSize(vector<int>& nums) {
        memset(st, -1, sizeof(st));
        int n = nums.size();
        for (int i:nums) {
            for (int j=2; j*j<=i; j++) {
                if (i%j == 0) {
                    int fi = ufind(i), fj1 = ufind(j), fj2 = ufind(i/j);
                    if (fj1 != fi) {
                        st[fj1] = fi;
                    }
                    if (fj2 != fi) {
                        st[fj2] = fi;
                    }
                }
            }
        }
        int ans = 0;
        for (int i:nums) {
            ans = max(ans, ++cnt[ufind(i)]);
        }
        return ans;
    }
};
```
