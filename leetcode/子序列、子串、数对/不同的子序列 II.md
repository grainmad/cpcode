## 题目

[977. 不同的子序列 II](https://leetcode.cn/problems/distinct-subsequences-ii/)


---


给定一个字符串 `s`，计算 `s` 的 **不同非空子序列** 的个数。因为结果可能很大，所以返回答案需要对** ****`10^9 + 7` 取余** 。

字符串的 **子序列** 是经由原字符串删除一些（也可能不删除）字符但不改变剩余字符相对位置的一个新字符串。

	- 例如，`"ace"` 是 `"***a***b***c***d***e***"` 的一个子序列，但 `"aec"` 不是。

 

**示例 1：**

**输入：**s = "abc"
**输出：**7
**解释：**7 个不同的子序列分别是 "a", "b", "c", "ab", "ac", "bc", 以及 "abc"。

**示例 2：**

**输入：**s = "aba"
**输出：**6
**解释：**6 个不同的子序列分别是 "a", "b", "ab", "ba", "aa" 以及 "aba"。

**示例 3：**

**输入：**s = "aaa"
**输出：**3
**解释：**3 个不同的子序列分别是 "a", "aa" 以及 "aaa"。

 

**提示：**

	- `1 <= s.length <= 2000`

	- `s` 仅由小写英文字母组成


## 题解


### 思路

`dp[i][j]` 前i个字符中以j结尾的不同子序列个数。
转移可从`dp[i-1][]`转移。`dp[i-1][]`包含了前i个字符的所有不同子序列。此时第i个字符的添加使得之前的不同子序列长度都增长了，仍然是不同子序列。对于第i个字符可视为长度为1的子序列。所以转移方程为$dp[i][j] = dp[i-1][j], dp[i][s[i]] = 1+\sum dp[i-1][]$


### 代码


```cpp
class Solution {
public:
    int dp[26];
    int distinctSubseqII(string s) {
        int MOD = 1e9+7;
        int n = s.size();
        for (int i=0; i<n; i++) {
            int x = 1;
            for (int j=0; j<26; j++) {
                x += dp[j];
                x %= MOD;
            }
            dp[s[i]-'a'] = x;
        }
        int ans = 0;
        for (int i=0; i<26; i++) {
            ans += dp[i];
            ans %= MOD;
        }
        return ans;
    }
};
```
