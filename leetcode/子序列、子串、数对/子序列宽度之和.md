## 题目

[927. 子序列宽度之和](https://leetcode.cn/problems/sum-of-subsequence-widths/)


---


一个序列的 **宽度** 定义为该序列中最大元素和最小元素的差值。

给你一个整数数组 `nums` ，返回 `nums` 的所有非空 **子序列** 的 **宽度之和** 。由于答案可能非常大，请返回对 `10^9^ + 7` **取余** 后的结果。

**子序列** 定义为从一个数组里删除一些（或者不删除）元素，但不改变剩下元素的顺序得到的数组。例如，`[3,6,2,7]` 就是数组 `[0,3,1,6,2,2,7]` 的一个子序列。

 

**示例 1：**

**输入：**nums = [2,1,3]
**输出：**6
**解释：**子序列为 [1], [2], [3], [2,1], [2,3], [1,3], [2,1,3] 。
相应的宽度是 0, 0, 0, 1, 1, 2, 2 。
宽度之和是 6 。

**示例 2：**

**输入：**nums = [2]
**输出：**0

 

**提示：**

	- `1 <= nums.length <= 10^5^`

	- `1 <= nums[i] <= 10^5^`


## 题解


### 思路

排序**

我们只需要考虑子序列的最大值和最小值，与子序列中元素的顺序无关。
可以考虑排序，排序后的所有子序列与原来所有子序列的贡献是一样的。

**solution 1**
排序后，可以考虑`nums[i]`作为子序列中最大值的贡献。
现在如果以`nums[j], j<i`作为子序列的最小值。那么对于`nums[k], j<k<i`的选与不选都不会影响区间`nums[i...j]`选取了`nums[i]`和`nums[j]`的子序列的贡献，即$2^{i-j-1}\times (nums[i]-nums[j])$。以`nums[i]`为结尾的所有子序列贡献为$\sum \limits_{k=0}^{i-1}(nums[i]-nums[k])\times 2^{i-k-1}$，所有子序列的最大最小值之差为$\sum \limits_{i=1}^{n-1} \sum \limits_{k=0}^{i-1}(nums[i]-nums[k])\times 2^{i-k-1}$

**solution 2**
排序后，考虑每个值做最大值和最小值的贡献。
`nums[i]`做最大值的子序列有$2^{i}$个，前面的$i$个数可选可不选。
`nums[i]`做最小值的子序列有$2^{n-i-1}$个，$i$后面的个数有$n-i-1$个可选可不选。
总贡献是$\sum \limits_{i=0}^{n-1}(2^{i}-2^{n-i-1})\times nums[i] = \sum \limits_{i=0}^{n-1}2^{i}\times(nums[i]-nums[n-i-1])$


### 代码


```cpp
//solution 1
class Solution {
public:
    int sumSubseqWidths(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        long long p = nums[0], q = 1, ans = 0, M = 1e9+7;
        int n = nums.size();
        for (int i=1; i<n; i++) {
            // cout << (q*nums[i]%M-p+M)%M << endl;
            ans += (q*nums[i]%M-p+M)%M;
            ans %= M;
            q = q*2+1;
            q %= M;
            p = p*2+nums[i];
            p %= M;
        }
        return ans;
    }
};
//solution 2
class Solution {
public:
    const int MOD = 1e9+7;
    int sumSubseqWidths(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size();
        long long ans = 0, p = 1;
        for (int i=0; i<n; i++) {
            ans += p*(nums[i]-nums[n-i-1]+MOD);
            ans %= MOD;
            p = p*2%MOD;
        }
        return ans;
    }
};
```
