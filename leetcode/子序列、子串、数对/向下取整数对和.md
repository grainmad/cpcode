## 题目

[1326. 向下取整数对和](https://leetcode.cn/problems/sum-of-floored-pairs/)


---


给你一个整数数组 `nums` ，请你返回所有下标对 `0 <= i, j < nums.length` 的 `floor(nums[i] / nums[j])` 结果之和。由于答案可能会很大，请你返回答案对`10^9^ + 7` **取余** 的结果。

函数 `floor()` 返回输入数字的整数部分。

 

**示例 1：**

**输入：**nums = [2,5,9]
**输出：**10
**解释：**
floor(2 / 5) = floor(2 / 9) = floor(5 / 9) = 0
floor(2 / 2) = floor(5 / 5) = floor(9 / 9) = 1
floor(5 / 2) = 2
floor(9 / 2) = 4
floor(9 / 5) = 1
我们计算每一个数对商向下取整的结果并求和得到 10 。

**示例 2：**

**输入：**nums = [7,7,7,7,7,7,7]
**输出：**49

 

**提示：**

	- `1 <= nums.length <= 10^5^`

	- `1 <= nums[i] <= 10^5^`


## 题解


### 思路

数论 类子序列**

用`c[i]`代表着小于等于`i`的数出现的次数。
由此有`c[2*i-1]-c[i-1]`个数除`i`向下取整为1，有`c[3*i-1]-c[2*i-1]`个数除`i`向下取整为2，... , 有`c[sz]-c[k*i-1]`个数向下取整为`k-1`。其中`k*i-1<=sz<(k+1)*i-1`，即`k=floor((sz+1)/i)`。
注意`i`出现的次数是`c[i]-c[i-1]`, 所以对于除`i`的总贡献是$(c[i]-c[i-1]) \sum \limits_{j=1}^{\lfloor \frac{sz+1}{i} \rfloor} c[sz]-c[j* i-1]$


### 代码


```cpp
class Solution {
public:
    long c[100005];
    int sumOfFlooredPairs(vector<int>& nums) {
        int sz = *max_element(nums.begin(), nums.end());
        for (auto i:nums) {
            c[i]++;
        }
        for (int i=1; i<=sz; i++) c[i] += c[i-1];
        // c[i] 小于等于i的个数

        long ans = 0;
        for (int i=1; i<=sz; i++) {
            if (c[i]-c[i-1])
            for (int j=i-1; j<=sz; j+=i) {
                ans += (c[sz]-c[j])*(c[i]-c[i-1]);
            }
        }
        return ans%(int(1e9+7));
    }
};
```
