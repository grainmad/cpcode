## 题目

[2135. 分割数组的最多方案数](https://leetcode.cn/problems/maximum-number-of-ways-to-partition-an-array/)


---


给你一个下标从 **0** 开始且长度为 `n` 的整数数组 `nums` 。**分割** 数组 `nums` 的方案数定义为符合以下两个条件的 `pivot` 数目：

	- `1 <= pivot < n`

	- `nums[0] + nums[1] + ... + nums[pivot - 1] == nums[pivot] + nums[pivot + 1] + ... + nums[n - 1]`

同时给你一个整数 `k` 。你可以将 `nums` 中 **一个** 元素变为 `k` 或 **不改变** 数组。

请你返回在 **至多** 改变一个元素的前提下，**最多** 有多少种方法 **分割** `nums` 使得上述两个条件都满足。

 

**示例 1：**

**输入：**nums = [2,-1,2], k = 3
**输出：**1
**解释：**一个最优的方案是将 nums[0] 改为 k 。数组变为 [***3***,-1,2] 。
有一种方法分割数组：
- pivot = 2 ，我们有分割 [3,-1 | 2]：3 + -1 == 2 。

**示例 2：**

**输入：**nums = [0,0,0], k = 1
**输出：**2
**解释：**一个最优的方案是不改动数组。
有两种方法分割数组：
- pivot = 1 ，我们有分割 [0 | 0,0]：0 == 0 + 0 。
- pivot = 2 ，我们有分割 [0,0 | 0]: 0 + 0 == 0 。

**示例 3：**

**输入：**nums = [22,4,-25,-20,-15,15,-16,7,19,-10,0,-13,-14], k = -33
**输出：**4
**解释：**一个最优的方案是将 nums[2] 改为 k 。数组变为 [22,4,***-33***,-20,-15,15,-16,7,19,-10,0,-13,-14] 。
有四种方法分割数组。

 

**提示：**

	- `n == nums.length`

	- `2 <= n <= 10^5^`

	- `-10^5^ <= k, nums[i] <= 10^5^`


## 题解


### 思路

前缀和+动态维护两个哈希表**

令`p[i]`是前i个数的前缀和。`p[0] = 0`
对于不需要修改的情况，直接看有多少个满足`p[i]==p[n]-p[i]`的i即可。（注意`i!=n`，我们将`p[i]`作为分割的左半部分，右半部分不能为空，所以`i<n`）。
对于修改`nums[i]`为`k`，`p[j]，j<i`不会改变，`p[j], j>=i`将变为`p[j]+k-nums[i]`。
令`d = k-nums[i]`
小于i的分割位置j满足`p[j] = p[n]+d-p[j], j<i`, L是动态维护的小于i的前缀和哈希表。可以在L中寻找`(p[n]+d)/2`出现次数。
大于等于i的分割位置j满足`p[j]+d = p[n]+d -(p[j]+d), j>=i`, R是动态维护大于等于i的前缀和哈希表。可以在R中寻找`(p[n]-d)/2`出现次数
这样对于每个修改位置都可以求出有多少种分割方式，然后维护最大值作为答案。


### 代码


```cpp
class Solution {
public:
    int waysToPartition(vector<int>& nums, int k) {
        int n = nums.size();
        vector<long> p(n+1, 0);
        unordered_map<long, int> L, R;
        for (int i=1; i<=n; i++) {
            p[i] = p[i-1]+nums[i-1];
            if (i<n) R[p[i]]++;
        }
        int ans = 0;
        if (p[n]%2 == 0) {
            ans = R[p[n]/2];
        }
        for (int i=1; i<=n; i++) {
            int d = k-nums[i-1];
            if ((p[n]+d)%2 == 0) {
                // p[j] = p[n]+d-p[j], j<i, L是动态维护的小于i的前缀和哈希表。在L中寻找(p[n]+d)/2
                // p[j]+d = p[n]+d -(p[j]+d), j>=i, R是动态维护大于等于i的前缀哈希表。在R中寻找(p[n]-d)/2
                ans = max(ans, L[(p[n]+d)/2]+R[(p[n]-d)/2]);
            }
            L[p[i]]++;
            R[p[i]]--;
        }
        return ans;
    }
};
```
