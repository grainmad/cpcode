## 题目

[2267. 删除元素后和的最小差值](https://leetcode.cn/problems/minimum-difference-in-sums-after-removal-of-elements/)


---


给你一个下标从 **0** 开始的整数数组 `nums` ，它包含 `3 * n` 个元素。

你可以从 `nums` 中删除 **恰好** `n` 个元素，剩下的 `2 * n` 个元素将会被分成两个 **相同大小** 的部分。

	- 前面 `n` 个元素属于第一部分，它们的和记为 `sum_first_` 。

	- 后面 `n` 个元素属于第二部分，它们的和记为 `sum_second_` 。

两部分和的 **差值** 记为 `sum_first_ - sum_second_` 。

	- 比方说，`sum_first_ = 3` 且 `sum_second_ = 2` ，它们的差值为 `1` 。

	- 再比方，`sum_first_ = 2` 且 `sum_second_ = 3` ，它们的差值为 `-1` 。

请你返回删除 `n` 个元素之后，剩下两部分和的 **差值的最小值** 是多少。

 

**示例 1：**

**输入：**nums = [3,1,2]
**输出：**-1
**解释：**nums 有 3 个元素，所以 n = 1 。
所以我们需要从 nums 中删除 1 个元素，并将剩下的元素分成两部分。
- 如果我们删除 nums[0] = 3 ，数组变为 [1,2] 。两部分和的差值为 1 - 2 = -1 。
- 如果我们删除 nums[1] = 1 ，数组变为 [3,2] 。两部分和的差值为 3 - 2 = 1 。
- 如果我们删除 nums[2] = 2 ，数组变为 [3,1] 。两部分和的差值为 3 - 1 = 2 。
两部分和的最小差值为 min(-1,1,2) = -1 。

**示例 2：**

**输入：**nums = [7,9,5,8,1,3]
**输出：**1
**解释：**n = 2 。所以我们需要删除 2 个元素，并将剩下元素分为 2 部分。
如果我们删除元素 nums[2] = 5 和 nums[3] = 8 ，剩下元素为 [7,9,1,3] 。和的差值为 (7+9) - (1+3) = 12 。
为了得到最小差值，我们应该删除 nums[1] = 9 和 nums[4] = 1 ，剩下的元素为 [7,5,8,3] 。和的差值为 (7+5) - (8+3) = 1 。
观察可知，最优答案为 1 。

 

**提示：**

	- `nums.length == 3 * n`

	- `1 <= n <= 10^5^`

	- `1 <= nums[i] <= 10^5^`


## 题解


### 思路

两次dp+枚举分割线**

令`l[i] = nums[0...i]中最小的n个数之和，i in [n-1, 2n-1]`， `r[i] = nums[i...3*n-1]中最大的n个数之和，i in [n, 2n]`。答案便是`min(l[i-1]-r[i]), i in [n, 2n]`


### 代码


```cpp
class Solution {
public:
    using ll = long long;
    long long minimumDifference(vector<int>& nums) {
        int n = nums.size()/3;
        vector<ll> l(3*n), r(3*n); //l[i] = nums[0...i] 中最小的n个数之和， r[i] = nums[i...3*n-1]中最大的n个数之和。
        // l[i] i in [n-1, 2n-1], r[i] i in [n, 2n] 
        priority_queue<ll> q;
        for (int i=0; i<n; i++) q.push(nums[i]), l[n-1] += nums[i];
        for (int i=n; i<2*n; i++) {
            q.push(nums[i]);
            l[i] = l[i-1] + nums[i]-q.top();
            q.pop();
        }
        priority_queue<ll, vector<ll>, greater<>> p;
        for (int i=2*n; i<3*n; i++) p.push(nums[i]), r[2*n] += nums[i];
        for (int i=2*n-1; i>=n; i--) {
            p.push(nums[i]);
            r[i] = r[i+1] + nums[i]-p.top();
            p.pop();
        }
        ll ans = l[n-1]-r[n];
        for (int i=n; i<=2*n; i++) {
            ans = min(ans, l[i-1]-r[i]);
        }
        return ans;
    }
};
```
