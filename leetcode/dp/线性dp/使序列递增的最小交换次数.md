## 题目

[819. 使序列递增的最小交换次数](https://leetcode.cn/problems/minimum-swaps-to-make-sequences-increasing/)


---


我们有两个长度相等且不为空的整型数组 `nums1` 和 `nums2` 。在一次操作中，我们可以交换 `nums1[i]` 和 `nums2[i]`的元素。

	- 例如，如果 `nums1 = [1,2,3,8]` ， `nums2 =[5,6,7,4]` ，你可以交换 `i = 3` 处的元素，得到 `nums1 =[1,2,3,4]` 和 `nums2 =[5,6,7,8]` 。

返回 *使 `nums1` 和 `nums2` **严格递增 **所需操作的最小次数* 。

数组 `arr` **严格递增** 且  `arr[0] < arr[1] < arr[2] < ... < arr[arr.length - 1]` 。

**注意：**

	- 用例保证可以实现操作。

 

**示例 1:**

**输入:** nums1 = [1,3,5,4], nums2 = [1,2,3,7]
**输出:** 1
**解释: **
交换 A[3] 和 B[3] 后，两个数组如下:
A = [1, 3, 5, 7] ， B = [1, 2, 3, 4]
两个数组均为严格递增的。

**示例 2:**

**输入:** nums1 = [0,3,5,8,9], nums2 = [2,1,4,6,9]
**输出:** 1

 

**提示:**

	- `2 <= nums1.length <= 10^5^`

	- `nums2.length == nums1.length`

	- `0 <= nums1[i], nums2[i] <= 2 * 10^5^`


## 题解


### 思路

对于第i个数考虑交换和不交换。
`dp1[i]`前`i+1`个数中，下标i交换能得到严格递增所需要的次数。
`dp2[i]`前`i+1`个数中，下标i不交换到能得到严格递增所需要的次数。
初始化`dp1[0] = 1`, `dp2[0] = 0`, 其余不合法状态为无穷大
由于肯定能得到实现操作。
所以
`nums1[i-1] < nums1[i] and nums2[i-1] < nums2[i]`
或者
`nums1[i-1] < nums2[i] and nums2[i-1] < nums1[i]`

对于前者
`i-1`位置如果交换了，那么`i`位置也要交换。所以`dp1[i] = min(dp1[i], dp1[i-1]+1)`
`i-1`位置如果没有交换，那么`i`位置也不需要交换。所以`dp2[i] = min(dp2[i], dp2[i-1])`
对于后者
`i-1`位置如果交换了，`i`位置不需要交换。所以`dp2[i] = min(dp2[i], dp1[i-1])`
`i-1`位置如果不交换，`i`位置需要交换。所以`dp1[i] = min(dp1[i], dp2[i-1]+1)`


### 代码


```cpp
class Solution {
public:
    int minSwap(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        vector<int> dp1(n, n+1), dp2(n, n+1);
        dp1[0] = 1; dp2[0] = 0;
        for (int i=1; i<n; i++) {
            if (nums1[i]>nums1[i-1] && nums2[i]>nums2[i-1]) {
                dp1[i] = min(dp1[i], dp1[i-1]+1);
                dp2[i] = min(dp2[i], dp2[i-1]);
            }
            if (nums1[i]>nums2[i-1] && nums2[i]>nums1[i-1]) {
                dp1[i] = min(dp1[i], dp2[i-1]+1);
                dp2[i] = min(dp2[i], dp1[i-1]);
            }
        }
        return min(dp1[n-1], dp2[n-1]);
    }
};
```
