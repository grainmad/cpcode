## 题目

[2017. 使二进制字符串字符交替的最少反转次数](https://leetcode.cn/problems/minimum-number-of-flips-to-make-the-binary-string-alternating/)


---


给你一个二进制字符串 `s` 。你可以按任意顺序执行以下两种操作任意次：

	- **类型 1 ：删除** 字符串 `s` 的第一个字符并将它 **添加** 到字符串结尾。

	- **类型 2 ：选择 **字符串 `s` 中任意一个字符并将该字符 **反转 **，也就是如果值为 `'0'` ，则反转得到 `'1'` ，反之亦然。

请你返回使 `s` 变成 **交替** 字符串的前提下， **类型 2 **的 **最少** 操作次数 。

我们称一个字符串是 **交替** 的，需要满足任意相邻字符都不同。

	- 比方说，字符串 `"010"` 和 `"1010"` 都是交替的，但是字符串 `"0100"` 不是。

 

**示例 1：**

**输入：**s = "111000"
**输出：**2
**解释：**执行第一种操作两次，得到 s = "100011" 。
然后对第三个和第六个字符执行第二种操作，得到 s = "10**1**01**0**" 。

**示例 2：**

**输入：**s = "010"
**输出：**0
**解释：**字符串已经是交替的。

**示例 3：**

**输入：**s = "1110"
**输出：**1
**解释：**对第二个字符执行第二种操作，得到 s = "1**0**10" 。

 

**提示：**

	- `1 <= s.length <= 10^5^`

	- `s[i]` 要么是 `'0'` ，要么是 `'1'` 。


## 题解


### 思路

两次dp，分割线**

dp
`pr[i][j]` 前`i`个以`j`结尾的前缀变为01串所需要的最小反转次数。
`su[i][j]` 前`i`个以`j`开头的后缀变为01串所需要的最小反转次数。
当长度为偶数时，min(pr[n-1][0], pr[n-1][1]) 为所求。
当长度为奇数时，当变为01串后，首位字符必定相同，由于操作1可以轮转，所以存在一对相邻字符相同的情况在轮转后可以是01串。


### 代码


```cpp
class Solution {
public:
    int minFlips(string s) {
        int n = s.size();
        vector<vector<int>> pr(n, vector<int>(2, 0)), su(n, vector<int>(2, 0));
        for (int i=0; i<n; i++) {
            pr[i][0] = (i>0?pr[i-1][1]:0) + (s[i] == '1');
            pr[i][1] = (i>0?pr[i-1][0]:0) + (s[i] == '0');
        }
        for (int i=n-1; i>=0; i--) {
            su[i][0] = (i<n-1?su[i+1][1]:0) + (s[i] == '1');
            su[i][1] = (i<n-1?su[i+1][0]:0) + (s[i] == '0');
        }
        if (n%2) {   
            int ans = min({pr[n-1][0], pr[n-1][1], su[0][0], su[0][1]});
            for (int i=0; i<n-1; i++) {
                for (int j=0; j<2; j++) {
                    for (int k=0; k<2; k++) {
                        ans = min(ans, pr[i][j]+su[i+1][k]);
                    }
                }
            }
            return ans;
        } else {
            return min(pr[n-1][0], pr[n-1][1]);
        }
    }
};
```
