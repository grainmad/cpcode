## 题目

[1900. 最接近目标价格的甜点成本](https://leetcode.cn/problems/closest-dessert-cost/)


---


你打算做甜点，现在需要购买配料。目前共有 `n` 种冰激凌基料和 `m` 种配料可供选购。而制作甜点需要遵循以下几条规则：

	- 必须选择 **一种** 冰激凌基料。

	- 可以添加 **一种或多种** 配料，也可以不添加任何配料。

	- 每种类型的配料 **最多两份** 。

给你以下三个输入：

	- `baseCosts` ，一个长度为 `n` 的整数数组，其中每个 `baseCosts[i]` 表示第 `i` 种冰激凌基料的价格。

	- `toppingCosts`，一个长度为 `m` 的整数数组，其中每个 `toppingCosts[i]` 表示 **一份** 第 `i` 种冰激凌配料的价格。

	- `target` ，一个整数，表示你制作甜点的目标价格。

你希望自己做的甜点总成本尽可能接近目标价格 `target` 。

返回最接近* *`target` 的甜点成本。如果有多种方案，返回 **成本相对较低** 的一种。

 

**示例 1：**

**输入：**baseCosts = [1,7], toppingCosts = [3,4], target = 10
**输出：**10
**解释：**考虑下面的方案组合（所有下标均从 0 开始）：
- 选择 1 号基料：成本 7
- 选择 1 份 0 号配料：成本 1 x 3 = 3
- 选择 0 份 1 号配料：成本 0 x 4 = 0
总成本：7 + 3 + 0 = 10 。

**示例 2：**

**输入：**baseCosts = [2,3], toppingCosts = [4,5,100], target = 18
**输出：**17
**解释：**考虑下面的方案组合（所有下标均从 0 开始）：
- 选择 1 号基料：成本 3
- 选择 1 份 0 号配料：成本 1 x 4 = 4
- 选择 2 份 1 号配料：成本 2 x 5 = 10
- 选择 0 份 2 号配料：成本 0 x 100 = 0
总成本：3 + 4 + 10 + 0 = 17 。不存在总成本为 18 的甜点制作方案。

**示例 3：**

**输入：**baseCosts = [3,10], toppingCosts = [2,5], target = 9
**输出：**8
**解释：**可以制作总成本为 8 和 10 的甜点。返回 8 ，因为这是成本更低的方案。

**示例 4：**

**输入：**baseCosts = [10], toppingCosts = [1], target = 1
**输出：**10
**解释：**注意，你可以选择不添加任何配料，但你必须选择一种基料。

 

**提示：**

	- `n == baseCosts.length`

	- `m == toppingCosts.length`

	- `1 <= n, m <= 10`

	- `1 <= baseCosts[i], toppingCosts[i] <= 10^4^`

	- `1 <= target <= 10^4^`


## 题解


### 思路

**

枚举法
设$n$为基料的种数，$m$为配料的种数。
三进制枚举，枚举每个配料选0次、1次或2次的情况。然后枚举选择的基料，选择最接近$target$的价格。总时间复杂度$O(n * m * 2^m)$

多重背包
可以将每种配料的价格看作物品的体积，物品的价格也是配料的价格，每种物品可以最多选择2次。然后求出前i种物品在j容量的情况下最多能有多大价值。由于我们选取的价值能大于`target`。不妨设容量的最大值为`2 * target`。
然后枚举所有dp状态，枚举基料，选额最接近target的价格。时间复杂度$O(m * n * target)$


### 代码


```cpp
class Solution {
public:
    int closestCost(vector<int>& baseCosts, vector<int>& toppingCosts, int target) {
        int n = baseCosts.size(), m = toppingCosts.size();
        int dif = 10005, ans = -1;
        int sz = 1;
        for (int i=0; i<m; i++) sz*=3;
        for (int i:baseCosts) {
            for (int j=0; j<sz; j++) {
                int cnt = i;
                for (int k=0,u=j; k<m; k++,u/=3) {
                    cnt += u%3*toppingCosts[k];
                }
                if (abs(cnt-target)<dif) {
                    dif = abs(cnt-target);
                    ans = cnt;
                } else if (abs(cnt-target)==dif) {
                    ans = min(ans, cnt);
                }
            }
        }
        return ans;
    }
};

class Solution {
public:
    int closestCost(vector<int>& baseCosts, vector<int>& toppingCosts, int target) {
        int n = baseCosts.size(), m = toppingCosts.size(), sz = target*2;
        vector<vector<int>> f(m+1, vector<int>(sz+1));
        for (int i=1; i<=m; i++) {
            for (int j=1; j<=sz; j++) {
                for (int k=0; k<=2; k++) {
                    if (j>=k*toppingCosts[i-1])
                    f[i][j] = max(f[i][j], f[i-1][j-k*toppingCosts[i-1]]+k*toppingCosts[i-1]);
                }
            }
        }
        int ans = 0, dif = 10005;
        for (int i=0; i<=m; i++) {
            for (int j=0; j<=sz; j++) {
                // printf("[%d,%d]=%d\n", i,j, f[i][j]);
                for (int k:baseCosts) {
                    if (abs(k+f[i][j]-target)<dif) {
                        dif = abs(k+f[i][j]-target);
                        ans = k+f[i][j];
                    } else if (abs(k+f[i][j]-target) == dif) {
                        ans = min(ans, k+f[i][j]);
                    }
                }
            }
        }
        return ans;
    }
};
```
