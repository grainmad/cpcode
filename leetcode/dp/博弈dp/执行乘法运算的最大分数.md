## 题目

[1896. 执行乘法运算的最大分数](https://leetcode.cn/problems/maximum-score-from-performing-multiplication-operations/)


---


给你两个长度分别 `n` 和 `m` 的整数数组 `nums` 和 `multipliers`** **，其中 `n >= m` ，数组下标 **从 1 开始** 计数。

初始时，你的分数为 `0` 。你需要执行恰好 `m` 步操作。在第 `i` 步操作（**从 1 开始** 计数）中，需要：

	- 选择数组 `nums` **开头处或者末尾处** 的整数 `x` 。

	- 你获得 `multipliers[i] * x` 分，并累加到你的分数中。

	- 将 `x` 从数组 `nums` 中移除。

在执行* *`m` 步操作后，返回 **最大** 分数*。*

 

**示例 1：**

**输入：**nums = [1,2,3], multipliers = [3,2,1]
**输出：**14
**解释：**一种最优解决方案如下：
- 选择末尾处的整数 3 ，[1,2,**3**] ，得 3 * 3 = 9 分，累加到分数中。
- 选择末尾处的整数 2 ，[1,**2**] ，得 2 * 2 = 4 分，累加到分数中。
- 选择末尾处的整数 1 ，[**1**] ，得 1 * 1 = 1 分，累加到分数中。
总分数为 9 + 4 + 1 = 14 。

**示例 2：**

**输入：**nums = [-5,-3,-3,-2,7,1], multipliers = [-10,-5,3,4,6]
**输出：**102
**解释：**一种最优解决方案如下：
- 选择开头处的整数 -5 ，[**-5**,-3,-3,-2,7,1] ，得 -5 * -10 = 50 分，累加到分数中。
- 选择开头处的整数 -3 ，[**-3**,-3,-2,7,1] ，得 -3 * -5 = 15 分，累加到分数中。
- 选择开头处的整数 -3 ，[**-3**,-2,7,1] ，得 -3 * 3 = -9 分，累加到分数中。
- 选择末尾处的整数 1 ，[-2,7,**1**] ，得 1 * 4 = 4 分，累加到分数中。
- 选择末尾处的整数 7 ，[-2,**7**] ，得 7 * 6 = 42 分，累加到分数中。
总分数为 50 + 15 - 9 + 4 + 42 = 102 。

 

**提示：**

	- `n == nums.length`

	- `m == multipliers.length`

	- `1 <= m <= 10^3^`

	- `m <= n <= 10^5^`` `

	- `-1000 <= nums[i], multipliers[i] <= 1000`


## 题解


### 思路

这个问题的子问题可以认为是左边或右边已经选择了若干个数字，剩余长度能获取的最大值。
可以定义状态`dp[i][j]`为已经选取了`i`个左侧选择了`j`个，右侧则选择了`i-j`个，在剩余未选的数字中能获取的最大值。我们的目标则是求`dp[0][0]`
很明显剩余长度长的是由剩余长度短的转移而来，而在选择时可以选左侧或者右侧的值。
对于`dp[i][j]`可以选择左侧，获得最大值为`dp[i+1][j+1] + nums[j]*multipliers[i]`, 也可以选择右侧，获得最大价值为`dp[i+1][j]+nums[n-(i+1-j)]*multipliers[i]`.
对于移动了m步，`dp[m][]`剩余能获取的价值为0
最后状态转移和初始状态为
`dp[i][j] = max(dp[i+1][j+1] + nums[j]*multipliers[i], dp[i+1][j]+nums[n-(i+1-j)]*multipliers[i])dp[m][] = 0`


### 代码


```cpp
#define N 1005
class Solution {
public:
    long dp[N][N]; //dp[i][j] 移动i步左侧选择j个，右侧选择i-j个，剩余未选的数能获得的最大值。
    int maximumScore(vector<int>& nums, vector<int>& multipliers) {
        int n = nums.size(), m = multipliers.size();
        memset(dp, 0x3f, sizeof(dp));
        long INF = 0x3f3f3f3f3f3f3f3f;
        function<long(int,int)> dfs= [&](int stp, int lc)->long {
            // cout << stp << " " << lc << endl;
            if (stp == m) return 0;
            if (dp[stp][lc] != INF) return dp[stp][lc];
            // cout << 1L*nums[lc]*multipliers[stp] << " " << 1L*nums[n-(stp+1-lc)]*multipliers[stp] << endl;
            return dp[stp][lc] = max(dfs(stp+1,lc+1)+1L*nums[lc]*multipliers[stp], dfs(stp+1,lc)+1L*nums[n-(stp+1-lc)]*multipliers[stp]);
        };
        return dfs(0,0);
    }
};
```
