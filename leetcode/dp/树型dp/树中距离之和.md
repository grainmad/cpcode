## 题目

[863. 树中距离之和](https://leetcode.cn/problems/sum-of-distances-in-tree/)


---


给定一个无向、连通的树。树中有 `n` 个标记为 `0...n-1` 的节点以及 `n-1` 条边 。

给定整数 `n` 和数组 `edges` ， `edges[i] = [a_i_, b_i_]`表示树中的节点 `a_i_` 和 `b_i_` 之间有一条边。

返回长度为 `n` 的数组 `answer` ，其中 `answer[i]` 是树中第 `i` 个节点与所有其他节点之间的距离之和。

 

**示例 1:**

**输入: **n = 6, edges = [[0,1],[0,2],[2,3],[2,4],[2,5]]
**输出: **[8,12,6,10,10,10]
**解释: **树如图所示。
我们可以计算出 dist(0,1) + dist(0,2) + dist(0,3) + dist(0,4) + dist(0,5) 
也就是 1 + 1 + 2 + 2 + 2 = 8。 因此，answer[0] = 8，以此类推。

**示例 2:**

[]

**输入:** n = 1, edges = []
**输出:** [0]

**示例 3:**

[]

**输入:** n = 2, edges = [[1,0]]
**输出:** [1,1]

 

**提示:**

	- `1 <= n <= 3 * 10^4^`

	- `edges.length == n - 1`

	- `edges[i].length == 2`

	- `0 <= a_i_, b_i_ < n`

	- `a_i_ != b_i_`

	- 给定的输入保证为有效的树


## 题解


### 思路

两次dfs
第一次dfs预处理出每颗子树的节点数cnt, 每颗子树根节点到其子节点的所有距离之和dis。
第二次dfs求出每个节点的到其余所有节点的距离之和ans。

具体做法，若求$ans[u]$值时，$ans[fa_u]$已经求出，$ans[fa_u]$减去u子树的贡献将作为$ans[u]$的**部分贡献**，即$val = ans[fa_u]-cnt[i]-dis[u]$，这里由于$u$子树有$cnt[u]$个节点，所以$u$和$fa_u$的边要算$cnt[u]$次。
此外$ans[u]$的**剩余贡献**还来自非$u$子树的节点$n-cnt[u]$，以及$u$子树到根的贡献$dis[u]$， 所以$ans[u] = ans[fa_u]-cnt[u]-dis[u]+n-cnt[u]+dis[u] = ans[fa_u]+n-2cnt[u]$
根节点特殊处理$ans[0] = dis[0]$

由于子问题没有重叠，严格来说不算是dp


### 代码


```cpp
class Solution {
public:
    #define N 30005
    vector<int> g[N];
    vector<int> sumOfDistancesInTree(int n, vector<vector<int>>& edges) {
        for (auto& i:edges) {
            g[i[0]].push_back(i[1]);
            g[i[1]].push_back(i[0]);
        }
        
        vector<int> ans(n), cnt(n), dis(n);
        function<void(int,int)> dfs1 = [&](int u, int fa) {
            cnt[u] = 1;
            for (int i:g[u]) {
                if (i == fa) continue;
                dfs1(i, u);
                cnt[u] += cnt[i];
                dis[u] += dis[i]+cnt[i];
            }
        };
        dfs1(0, -1);
        // for (int i=0; i<n; i++) {
        //     cout << i << " " << cnt[i] << " " << dis[i] << endl;
        // }
        function<void(int,int)> dfs2 = [&](int u, int fa) {
            ans[u] = u ? ans[fa]+n-2*cnt[u] : dis[u];
            for (int i:g[u]) {
                if (i == fa) continue;
                dfs2(i, u);
            }
        };
        dfs2(0, -1);
        return ans;
    }
};
```
