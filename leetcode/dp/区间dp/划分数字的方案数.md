## 题目

[2091. 划分数字的方案数](https://leetcode.cn/problems/number-of-ways-to-separate-numbers/)


---


你写下了若干 **正整数** ，并将它们连接成了一个字符串 `num` 。但是你忘记给这些数字之间加逗号了。你只记得这一列数字是 **非递减** 的且 **没有** 任何数字有前导 0 。

请你返回有多少种可能的 **正整数数组** 可以得到字符串 `num` 。由于答案可能很大，将结果对 `10^9^ + 7` **取余** 后返回。

 

**示例 1：**

**输入：**num = "327"
**输出：**2
**解释：**以下为可能的方案：
3, 27
327

**示例 2：**

**输入：**num = "094"
**输出：**0
**解释：**不能有数字有前导 0 ，且所有数字均为正数。

**示例 3：**

**输入：**num = "0"
**输出：**0
**解释：**不能有数字有前导 0 ，且所有数字均为正数。

**示例 4：**

**输入：**num = "9999999999999"
**输出：**101

 

**提示：**

	- `1 <= num.length <= 3500`

	- `num` 只含有数字 `'0'` 到 `'9'` 。


## 题解


### 思路

dp预处理优化 前缀和优化**

动态规划往往难在找子问题，其次本题的状态转移需要分情况考虑且需要优化，另外还有数据量会卡常。

首先对于`'0'`开头的字符串是没有可行拆分数的。答案直接是$0$。
接下来需要寻找重叠的子问题。
试想每个前缀的拆分方案的关系。
前缀与前缀之间最直接的差别就在于最后一个拆分的数，而最后一个拆分的数长度是可变的。
所以自然会想到二维$dp$，且数据量也暗示着需要$O(n^2)$时间复杂度的算法。但是经验告诉我二维的dp在转移时往往还需要$O(n)$，总时间复杂度将达到$O(n^3)$，这个题还需要找某种性质优化。

可以定义状态$f_{i,j} (0<i,j\le n)$ 为前j个字符可行的分割方案数，且最后一个分割的字符是$num(i,j)$。
为方便描述，定义$num(i,j)$为$num$从第$i$个字符到第$j$个字符形成的无前导$0$的数字；定义$len(i,j)$为$num$从第$i$个字符到第$j$个字符形成的无前导$0$的数字的长度。
我们需要求的答案就是$\sum \limits_{i=1}^n f_{i,n}$

对于$f_{i,j}$肯定是由$f_{k,i-1}$转移过来，这里的$k$需要满足$num(k,i-1)<num(i,j)$，这其中的$k$取值范围是多少呢？
考虑$num(k,i-1)$和$num(i,j)$长度关系：

- 当$len(k,i-1) > len(i,j)$，必定有$num(k,i-1) > num(i,j)$。不满足非递减分割。
- 当$len(k,i-1) < len(i,j)$，必定有$num(k,i-1) < num(i,j)$。此时$k$满足$i-1-k+1 < j-i+1 \Rightarrow k>2* i-j-1$。此时$\sum \limits_{k=2* i-j}^{i-1} f_{k,i-1}$作为$f_{i,j}$的部分贡献。
- 当$len(k,i-1) = len(i,j)$，长度相等的数字比较大小只需要比较字典序即可。此时$k$满足$i-1-k+1 = j-i+1 \Rightarrow k=2* i-j-1$，也就是说只要$num(2* i-j-1, i-1) \le num(i, j)$即可让$f_{2* i-j-1, i-1}$作为$f_{i,j}$的贡献。

以上过程存在两个问题，对于求$\sum \limits_{k=2* i-j}^{i-1} f_{k,i-1}$的需要$O(n)$；对于$len(k,i-1) = len(i,j)$时字典序的比较也需要$O(n)$。这都会让时间复杂度达到$O(n^3)$

现在考虑怎么优化。
可以定义$p_{i,j} = \sum \limits_{k=i}^{j} f_{k, j}$，在求转移时维护这样一个前缀和实现$O(1)$转移，但是实际上$p_{1,n}$就是我们要求的答案。不如直接将$p_{i,j}$代替$f_{i,j}$作为进行状态转移，只需在求$p_{i,j}$时累加$p_{i+1,j}$就可以累加前缀和了。
这里相当于定义状态$p_{i,j} (0<i,j\le n)$ 为前$j$个字符可行的分割方案数，且最后一个分割的字符长度不超过$len(i,j)$。

对于比较字典序的优化可以动态规划预处理出任意后缀的最长公共前缀。
定义$pre_{i,j}, 0<i,j\le n$为$num(i,n)$与$num(j,n)$的最长公共前缀。

$pre_{i,j} =
\left\{ \begin{array}{ll}
pre_{i+1,j+1}+1, & num[i-1] = num[j-1]\\
0 & num[i-1] \neq num[j-1]
\end{array}\right.$

至此，求得$pre$可以使得$O(1)$定位到第一个不相等的字符
将比较字典序时间复杂度降为$O(1)$

另外对于$dp$初始化由于将前i个字符单独分割成一个数字是一种方案，我们可以初始化所有$p_{1,i}=1$

细节方面
每个测试用例数组大小应该根据$n$来定。
对于出现$k<1$的情况，实际上$len(1,i-1)$是小于$len(i,j)$的，所以直接由$p_{1, i-1}$转移即可。


### 代码


```cpp
class Solution {
public:
    // using ll = long long;
    const int MOD = 1e9+7;
    #define N 3505
    // int f[N][N];//f[i][j] 在前j个数的划分中以第i个字符到第j个字符作为最后一个划分的数（即num[i-1, j-1]）的可行方案数。
    // int p[N][N];//p[i][j] = f[i...j][j]
    // int pre[N][N];//pre[i][j] 第i个字符开头的后缀与第j个字符开头的后缀的公共前缀长度，即num[i-1, n-1]与num[j-1, n-1]的最长公共前缀
    int numberOfCombinations(string num) {
        if (num[0] == '0') return 0;
        int n = num.size();
        int p[n+5][n+5], pre[n+5][n+5];
        memset(p, 0, sizeof(p));
        memset(pre, 0, sizeof(pre));
        for (int i=n; i>0; i--) {
            for (int j=n; j>0; j--) {
                if (num[i-1] == num[j-1]) pre[i][j] = pre[i+1][j+1]+1;
                else pre[i][j] = 0;
                // printf("pre[%d,%d]=%d\n",i,j,pre[i][j]);
            }
        }
        for (int i=1; i<=n; i++) p[1][i] = 1;
        for (int j=1; j<=n; j++) {
            for (int i=j; i>0; i--) {
                p[i][j] += p[i+1][j];
                p[i][j] %= MOD;
                int k = 2*i-j-1;
                if (num[i-1] == '0') continue;//不可前导零
                if (k >= 1) {
                    int u = pre[k][i];
                    if (u >= j-i+1 || num[u+k-1] <= num[u+i-1]) {
                        //公共前缀长度大于等于num[i,j]的长度则说明num[2*i-j-1, i-1] = num[i, j]
                        //公共前缀小于num[i, j]的长度则需要比较第一个不相等的字符
                        p[i][j] += p[k][i-1];
                    } else {
                        p[i][j] += p[k+1][i-1];
                    }
                } else {
                    p[i][j] += p[1][i-1];
                }
                p[i][j] %= MOD;
                // printf("p[%d,%d]=%d\n",i,j,p[i][j]);
            }
        }
        return p[1][n];
    }
};
```
