## 题目

[2067. 扣分后的最大得分](https://leetcode.cn/problems/maximum-number-of-points-with-cost/)


---

**提示：**

	- `m == points.length`

## 题解


### 思路

前缀和优化**

容易想到$dp[i][j]$为第i行第j列的最大获得分，$dp[i][j] = \max \limits_{0 \le c < m}\{dp[i-1][c]+points[i][j]-|j-c|\}$, 时间复杂度为$O(n*m^2)$。points矩阵的形状为$n*m$，$m*n$数量级在$1e5$内, 当$m$远大于$n$时会超时。
对于`dp[i][]`的转移，我们可以预先求出$l[j]=\max \limits_{0\le c < j} \{dp[i-1][c]-|j-c| \}$，由于$l[j]$与$l[j-1]$存在递推关系$l[j] = \max \{l[j-1]-1, dp[i-1][j]\}$，我们只需要$O(n)$可以预处理出`l[]`,同理也可以预处理出`r[]`，$r[j]=\max \limits_{j\le c < n} \{dp[i-1][c]-|j-c| \}$。这是状态转移可以优化为$dp[i][j] = max\{l[j],r[j]\}+points[i][j]$，时间复杂度优化为$O(n*m)$


### 代码


```cpp
class Solution {
public:
    const int NINF = 0xf3f3f3f3;
    long long maxPoints(vector<vector<int>>& points) {
        int n = points.size(), m = points[0].size();
        // cout << n << " " << m << endl;
        vector<vector<long>> dp(n, vector<long>(m, NINF));
        for (int i=0; i<m; i++) dp[0][i] = points[0][i];
        for (int i=1; i<n; i++) {
            vector<long> l(m, dp[i-1][0]), r(m, dp[i-1][m-1]);
            for (int j=1; j<m; j++) l[j] = max(l[j-1]-1, dp[i-1][j]);
            for (int j=m-2; j>=0; j--) r[j] = max(r[j+1]-1, dp[i-1][j]);
            for (int j=0; j<m; j++) {
                dp[i][j] = max(dp[i][j], points[i][j]+max(l[j],r[j]));
                // cout << dp[i][j] << " ";
            }
            // cout << endl;
        }
        return *max_element(dp[n-1].begin(), dp[n-1].end());
    }
};
```
