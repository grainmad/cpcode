## 题目

[1555. 切披萨的方案数](https://leetcode.cn/problems/number-of-ways-of-cutting-a-pizza/)


---


给你一个 `rows x cols` 大小的矩形披萨和一个整数 `k` ，矩形包含两种字符： `'A'` （表示苹果）和 `'.'` （表示空白格子）。你需要切披萨 `k-1` 次，得到 `k` 块披萨并送给别人。

切披萨的每一刀，先要选择是向垂直还是水平方向切，再在矩形的边界上选一个切的位置，将披萨一分为二。如果垂直地切披萨，那么需要把左边的部分送给一个人，如果水平地切，那么需要把上面的部分送给一个人。在切完最后一刀后，需要把剩下来的一块送给最后一个人。

请你返回确保每一块披萨包含 **至少** 一个苹果的切披萨方案数。由于答案可能是个很大的数字，请你返回它对 10^9 + 7 取余的结果。

**输出：**3

**输出：**1

 

**提示：**

	- `1 <= rows, cols <= 50`

	- `rows == pizza.length`

	- `cols == pizza[i].length`

	- `1 <= k <= 10`

	- `pizza` 只包含字符 `'A'` 和 `'.'` 。


## 题解


### 思路

动态规划
`dp[i][j][c]`为从左上角(i,j)到右下角(n-1,m-1)的矩形切割c刀分成c+1块都含苹果的方案数。
那么`dp[i][j][c]`在`pizza[i][j...n-1] != A`时能从`dp[i+1][j][c]`转移吗？不能。
正解$dp[i][j][c] = \sum \limits_{x \in [i+1, n-1]} dp[i][x][c-1] + \sum \limits_{y \in [j+1, m-1]} dp[i][y][c-1]$，转移时注意切出的块需要含有苹果。可以通过前缀和判断。


### 代码


```cpp
class Solution {
public:
    int ways(vector<string>& pizza, int k) {
        long M = 1e9+7;
        int n = pizza.size(), m = pizza[0].size();
        long dp[n+1][m+1][k+1];
        memset(dp, 0, sizeof(dp));
        for (int i=n-1; i>=0; i--) {
            for (int j=m-1; j>=0; j--) {
                dp[i][j][0] = (pizza[i][j]=='A' || dp[i+1][j][0] || dp[i][j+1][0]);
            }
        }
        vector<vector<int>> p(n+1, vector<int>(m+1, 0));
        for (int i=1; i<=n; i++) {
            for (int j=1; j<=m; j++) {
                p[i][j] = p[i][j-1] + p[i-1][j] - p[i-1][j-1] + (pizza[i-1][j-1]=='A');
            }
        }
        auto cnt = [&](int x1, int y1, int x2, int y2) {
            return p[x2+1][y2+1]-p[x1][y2+1]-p[x2+1][y1] + p[x1][y1];
        };
        for (int i=n-1; i>=0; i--) {
            for (int j=m-1; j>=0; j--) {
                for (int c=1; c<k; c++) {
                    for (int a=i; a<n; a++) {
                        if (cnt(i,j,a,m-1)) dp[i][j][c] = (dp[i][j][c] + dp[a+1][j][c-1])%M;
                    }
                    for (int b=j; b<m; b++) {
                        if (cnt(i,j,n-1,b)) dp[i][j][c] = (dp[i][j][c] + dp[i][b+1][c-1])%M;
                    }
                }
            }
        }
        
        // for (int i=n-1; i>=0; i--) {
        //     for (int j=m-1; j>=0; j--) {
        //         for (int c=1; c<k; c++) {
        //             printf("%d,%d,%d=%d\n", i, j, c, dp[i][j][c]);
        //         }
        //     }
        // }
        return dp[0][0][k-1];
    }
};
```
