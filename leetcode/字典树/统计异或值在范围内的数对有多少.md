## 题目

[1907. 统计异或值在范围内的数对有多少](https://leetcode.cn/problems/count-pairs-with-xor-in-a-range/)


---


给你一个整数数组 `nums` （下标 **从 0 开始** 计数）以及两个整数：`low` 和 `high` ，请返回 **漂亮数对** 的数目。

**漂亮数对** 是一个形如 `(i, j)` 的数对，其中 `0 <= i < j < nums.length` 且 `low <= (nums[i] XOR nums[j]) <= high` 。

 

**示例 1：**

**输入：**nums = [1,4,2,7], low = 2, high = 6
**输出：**6
**解释：**所有漂亮数对 (i, j) 列出如下：
    - (0, 1): nums[0] XOR nums[1] = 5 
    - (0, 2): nums[0] XOR nums[2] = 3
    - (0, 3): nums[0] XOR nums[3] = 6
    - (1, 2): nums[1] XOR nums[2] = 6
    - (1, 3): nums[1] XOR nums[3] = 3
    - (2, 3): nums[2] XOR nums[3] = 5

**示例 2：**

**输入：**nums = [9,8,4,2,1], low = 5, high = 14
**输出：**8
**解释：**所有漂亮数对 (i, j) 列出如下：
​​​​​    - (0, 2): nums[0] XOR nums[2] = 13
    - (0, 3): nums[0] XOR nums[3] = 11
    - (0, 4): nums[0] XOR nums[4] = 8
    - (1, 2): nums[1] XOR nums[2] = 12
    - (1, 3): nums[1] XOR nums[3] = 10
    - (1, 4): nums[1] XOR nums[4] = 9
    - (2, 3): nums[2] XOR nums[3] = 6
    - (2, 4): nums[2] XOR nums[4] = 5

 

**提示：**

	- `1 <= nums.length <= 2 * 10^4^`

	- `1 <= nums[i] <= 2 * 10^4^`

	- `1 <= low <= high <= 2 * 10^4^`


## 题解


### 思路

设计一个数据结构，可以高效地查询一个集合中有多少个满足$x \oplus a \le b$的$x$的个数

然后对于求`nums[i]`作为第二关键字的漂亮数对，只需要在集合`nums[0...i-1]`中查找满足$x \oplus nums[i] \le low-1$的$x$个数$cnt1$，查找满足$x \oplus nums[i] \le high$的$x$个数$cnt2$，用$cnt2-cnt1$即可。

求出所有`nums[i]`作为第二关键字的漂亮数对的和就是答案。

怎么设计这样的数据结构，我们可以把集合中的每个x看作一个固定位数二进制数（位数不够的在前补0）。然后将它们都插入到一个字典树中，每个节点记录前缀个数。

现在要在字典树中求满足$x \oplus a \le b$的$x$的个数

设$a_i$为数字$a$从高位数起的第$i$位。

我们只需要在字典树中寻找满足$x_i \oplus a_i < b_i$的$x_i$的节点前缀个数累加起来，再加上满足$x \oplus a = b$的$x$个数即可。

具体做法，在字典树中移动节点确保$x_i \oplus a_i = b_i$：

1. 当$b_i = 0$时，当前节点$x_i$应该移动到$a_i$节点

2. 当$b_i = 1$时，当前节点$x_i$应该移动到$1-a_i$节点，此外$a_i \oplus a_i = 0 < b_i = 1$，需要累加$a_i$节点的统计的前缀数。

以上过程求出的是$x \oplus a < b$的$x$的个数。而我们需要求出的是$x \oplus a \le b$的$x$的个数。因此在此过程中遇到不存在节点则直接返回累计的数即可；如果所有位数都遍历完了，则当前节点统计的前缀个数就是满足$x \oplus a = b$的$x$个数。累加后返回就求出了满足$x \oplus a \le b$的$x$的个数。
