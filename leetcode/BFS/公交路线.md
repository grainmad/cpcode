## 题目

[833. 公交路线](https://leetcode.cn/problems/bus-routes/)


---


给你一个数组 `routes` ，表示一系列公交线路，其中每个 `routes[i]` 表示一条公交线路，第 `i` 辆公交车将会在上面循环行驶。

	- 例如，路线 `routes[0] = [1, 5, 7]` 表示第 `0` 辆公交车会一直按序列 `1 -> 5 -> 7 -> 1 -> 5 -> 7 -> 1 -> ...` 这样的车站路线行驶。

现在从 `source` 车站出发（初始时不在公交车上），要前往 `target` 车站。 期间仅可乘坐公交车。

求出 **最少乘坐的公交车数量** 。如果不可能到达终点车站，返回 `-1` 。

 

**示例 1：**

**输入：**routes = [[1,2,7],[3,6,7]], source = 1, target = 6
**输出：**2
**解释：**最优策略是先乘坐第一辆公交车到达车站 7 , 然后换乘第二辆公交车到车站 6 。 

**示例 2：**

**输入：**routes = [[7,12],[4,5,15],[6],[15,19],[9,12,13]], source = 15, target = 12
**输出：**-1

 

**提示：**

	- `1 <= routes.length <= 500`.

	- `1 <= routes[i].length <= 10^5^`

	- `routes[i]` 中的所有值 **互不相同**

	- `sum(routes[i].length) <= 10^5^`

	- `0 <= routes[i][j] < 10^6^`

	- `0 <= source, target < 10^6^`


## 题解


### 思路

**

将每条线路的公交车看作点，若两个不同的线路a和b中存在相同的站点则可视为a和b存在一条权值为1的边。
我们用`g[i]`代表着包含i站点的公交编号。
对于包含了source站点的公交车加入队列。
对于队首公交车，若所到达站点包含target则通过当前广搜层数返回所需要搭乘的公交车辆数。
另外通过g得到与当前点所连接的点。若为搜索过则加入队列。


### 代码


```cpp
class Solution {
public:
    vector<int> g[1000006];
    int vis[505];
    int numBusesToDestination(vector<vector<int>>& routes, int source, int target) {
        if (source == target) return 0;
        queue<int> que;
        int n = routes.size();
        for (int i=0; i<n; i++) {
            for (int j:routes[i]) {
                g[j].push_back(i);
                if (j == source) {
                    que.push(i);
                    vis[i] = 1;
                }
            }
        }
        int stp = 1;
        while (!que.empty()) {
            int sz = que.size();
            for (int c=0; c<sz; c++) {
                int u = que.front(); que.pop();
                for (int i:routes[u]) {
                    if (i == target) return stp;
                    for (int j:g[i]) {
                        if (vis[j]) continue;
                        vis[j] = 1;
                        que.push(j);
                    }
                }
                
            }
            stp++;
        }
        return -1;
    }
};
```
