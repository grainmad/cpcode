## 题目

[1122. 最长重复子串](https://leetcode.cn/problems/longest-duplicate-substring/)


---


给你一个字符串 `s` ，考虑其所有 *重复子串* ：即 `s` 的（连续）子串，在 `s` 中出现 2 次或更多次。这些出现之间可能存在重叠。

返回 **任意一个** 可能具有最长长度的重复子串。如果 `s` 不含重复子串，那么答案为 `""` 。

 

**示例 1：**

**输入：**s = "banana"
**输出：**"ana"

**示例 2：**

**输入：**s = "abcd"
**输出：**""

 

**提示：**

	- `2 <= s.length <= 3 * 10^4^`

	- `s` 由小写英文字母组成


## 题解


### 思路

二分+字符串哈希**

同2223


### 代码


```cpp
class Solution {
public:
    using ull = unsigned long long;
    const int BASE = 151;
    string longestDupSubstring(string s) {
        int n = s.size();
        vector<ull> H(n+1, 0), B(n+1, 1);
        for (int i=1; i<=n; i++) {
            H[i] = H[i-1]*BASE + s[i-1];
            B[i] = B[i-1]*BASE;
        }
        int p = -1, w = -1;
        function<bool(int)> check = [&](int len) {
            unordered_map<ull,int> mp;
            for (int i=len; i<=n; i++) {
                if (++mp[H[i]-H[i-len]*B[len]] == 2) {
                    p = i;
                    w = len;
                    return true;
                }
            }
            return false;
        };
       	 int l = 1, r = n+1;
       	 while (l<r) {
       	     int m = l+r>>1;
       	     if (check(m)) {
       	         l = m + 1;
       	     } else r = m;
       	 }
       	 if (p == -1) return "";
       	 return s.substr(p-w, w);
    }
};
```
