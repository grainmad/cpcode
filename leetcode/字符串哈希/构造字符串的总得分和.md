## 题目

[2326. 构造字符串的总得分和](https://leetcode.cn/problems/sum-of-scores-of-built-strings/)


---


你需要从空字符串开始 **构造** 一个长度为 `n` 的字符串 `s` ，构造的过程为每次给当前字符串 **前面** 添加 **一个** 字符。构造过程中得到的所有字符串编号为 `1` 到 `n` ，其中长度为 `i` 的字符串编号为 `s_i_` 。

	- 比方说，`s = "abaca"` ，`s_1_ == "a"` ，`s_2_ == "ca"` ，`s_3_ == "aca"` 依次类推。

`s_i_` 的 **得分** 为 `s_i_` 和 `s_n_` 的 **最长公共前缀** 的长度（注意 `s == s_n_` ）。

给你最终的字符串 `s` ，请你返回每一个* *`s_i_` 的 **得分之和** 。

 

**示例 1：**

**输入：**s = "babab"
**输出：**9
**解释：**
s_1_ == "b" ，最长公共前缀是 "b" ，得分为 1 。
s_2_ == "ab" ，没有公共前缀，得分为 0 。
s_3_ == "bab" ，最长公共前缀为 "bab" ，得分为 3 。
s_4_ == "abab" ，没有公共前缀，得分为 0 。
s_5_ == "babab" ，最长公共前缀为 "babab" ，得分为 5 。
得分和为 1 + 0 + 3 + 0 + 5 = 9 ，所以我们返回 9 。

**示例 2 ：**

**输入：**s = "azbazbzaz"
**输出：**14
**解释：**
s_2_ == "az" ，最长公共前缀为 "az" ，得分为 2 。
s_6_ == "azbzaz" ，最长公共前缀为 "azb" ，得分为 3 。
s_9_ == "azbazbzaz" ，最长公共前缀为 "azbazbzaz" ，得分为 9 。
其他 s_i_ 得分均为 0 。
得分和为 2 + 3 + 9 = 14 ，所以我们返回 14 。

 

**提示：**

	- `1 <= s.length <= 10^5^`

	- `s` 只包含小写英文字母。


## 题解


### 思路

二分+字符串哈希**

字符串哈希+二分
$O(n)$时间复杂度预处理
$O(1)$时间复杂度求子串的哈希值。
设字符串为$s = s_0s_1\cdots s_{n-1}$
前缀串哈希函数$h_i$是s长度为i的前缀串$s_0s_1\cdots s_{i-1}$的哈希值。
前缀串哈希函数定义为$h_n = \sum \limits_{i=0}^{n-1} s_i* sigma^{n-i-1} \mod M$
其中 $sigma$至少为字符集的大小，M是大质数。
通过递推式
$h_0 = 0$
$h_i = (h_{i-1}* sigma+s_{i-1}) \mod M$
可以$O(n)$预处理求得$h_{0...n}$

如何求子串$s_as_{a+1}\cdots s_{b-1}s_{b}$的哈希？
哈希值应当为$\sum \limits_{i=a}^{b} s_i* sigma^{b-i} \mod M$
注意到
$h_{b+1} = \sum \limits_{i=0}^{b} s_i* sigma^{b-i} \mod M$
$h_{b+1} = \sum \limits_{i=0}^{a-1} s_i* sigma^{b-i} \mod M+\sum \limits_{i=a}^{b} s_i* sigma^{b-i} \mod M$
$h_{b+1} =\sum \limits_{i=0}^{a-1} s_i* sigma^{a-i-1}* sigma^{b-a+1} \mod M+\sum \limits_{i=a}^{b} s_i* sigma^{b-i} \mod M$$h_{b+1} =h_{a}* sigma^{b-a+1} \mod M+\sum \limits_{i=a}^{b} s_i* sigma^{b-i} \mod M$

可以用$h_{b+1}-h_a* sigma^{b-a+1}$表示
因此也要预处理求出$sigma$的幂次


### 代码


```cpp
class Solution {
public:
    using ull = unsigned long long;
    using ll = long long;
    const int BASE = 131;
    long long sumScores(string s) {
        int n = s.size();
        vector<ull> H(n+1, 0), B(n+1, 1);
        for (int i=1; i<=n; i++) {
            H[i] = H[i-1]*BASE + s[i-1];
            B[i] = BASE*B[i-1];
        }
        ll ans = 0;
        for (int i=0; i<n; i++) {
            ll l = i+1, r = n+1;
            while (l<r) {
                ll m = l+r>>1;
                if (H[m]-H[i]*B[m-i] == H[m-i]) { // s[i...m-1] == s[0...m-i-1]
                    l = m+1;
                } else r = m;
            }
            ans += r-i-1;
        }
        return ans;
    }
};
```
