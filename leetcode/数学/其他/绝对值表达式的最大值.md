## 题目

[1230. 绝对值表达式的最大值](https://leetcode.cn/problems/maximum-of-absolute-value-expression/)


---


给你两个长度相等的整数数组，返回下面表达式的最大值：

`|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|`

其中下标 `i`，`j` 满足 `0 <= i, j < arr1.length`。

 

**示例 1：**

**输入：**arr1 = [1,2,3,4], arr2 = [-1,4,5,6]
**输出：**13

**示例 2：**

**输入：**arr1 = [1,-2,-5,0,10], arr2 = [0,-2,-1,-7,-4]
**输出：**20

 

**提示：**

	- `2 <= arr1.length == arr2.length <= 40000`

	- `-10^6 <= arr1[i], arr2[i] <= 10^6`


## 题解


### 思路

简化模型**

`|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|`去掉绝对值后有八种情况
`arr1[i] - arr1[j] + arr2[i] - arr2[j] + i - j = arr1[i] + arr2[i] + i - ( arr1[j] + arr2[j] + j )`

`arr1[i] - arr1[j] + arr2[i] - arr2[j] - i + j = arr1[i] + arr2[i] - i - ( arr1[j] + arr2[j] - j )`

`arr1[i] - arr1[j] - arr2[i] + arr2[j] + i - j = arr1[i] - arr2[i] + i - ( arr1[j] - arr2[j] + j )`

`arr1[i] - arr1[j] - arr2[i] + arr2[j] - i + j = arr1[i] - arr2[i] - i - ( arr1[j] - arr2[j] - j )`

`arr1[i] + arr1[j] + arr2[i] - arr2[j] + i - j = -arr1[i] + arr2[i] + i - ( -arr1[j] + arr2[j] + j )`

`arr1[i] + arr1[j] + arr2[i] - arr2[j] - i + j = -arr1[i] + arr2[i] - i - ( -arr1[j] + arr2[j] - j )`

`arr1[i] + arr1[j] - arr2[i] + arr2[j] + i - j = -arr1[i] - arr2[i] + i - ( -arr1[j] - arr2[j] + j )`

`arr1[i] + arr1[j] - arr2[i] + arr2[j] - i + j = -arr1[i] - arr2[i] - i - ( -arr1[j] - arr2[j] - j )`

i和j可以互换，于是可以分别维护`arr1[i] + arr2[i] + i`, `arr1[i] + arr2[i] - i`, `arr1[i] - arr2[i] + i`, `arr1[i] - arr2[i] - i`的最大值和最小值，最后得到答案是四个”最大值-最小值“的最大值。

起始就是去完绝对值后生成了4个函数，然后求函数的最大值-最小值。


### 代码


```cpp
class Solution {
public:
    int d[4][40005];
    int dir[4][2] = {{1,1},{1,-1},{-1,1},{-1,-1}};
    int maxAbsValExpr(vector<int>& arr1, vector<int>& arr2) {
        int n = arr1.size();
        for (int i=0; i<n; i++) {
            for (int j=0; j<4; j++) {
                d[j][i] = arr1[i]+dir[j][0]*arr2[i]+dir[j][1]*i;
            }
        }
        return max({
            *max_element(d[0], d[0]+n)-*min_element(d[0], d[0]+n),
            *max_element(d[1], d[1]+n)-*min_element(d[1], d[1]+n),
            *max_element(d[2], d[2]+n)-*min_element(d[2], d[2]+n),
            *max_element(d[3], d[3]+n)-*min_element(d[3], d[3]+n)
        });
    }
};
```
