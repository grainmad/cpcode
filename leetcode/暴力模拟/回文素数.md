## 题目

[897. 回文质数](https://leetcode.cn/problems/prime-palindrome/)


---


给你一个整数 `n` ，返回大于或等于 `n` 的最小 **回文质数**。

一个整数如果恰好有两个除数：`1` 和它本身，那么它是 **质数** 。注意，`1` 不是质数。

	- 例如，`2`、`3`、`5`、`7`、`11` 和 `13` 都是质数。

一个整数如果从左向右读和从右向左读是相同的，那么它是** 回文数 **。

	- 例如，`101` 和 `12321` 都是回文数。

测试用例保证答案总是存在，并且在 `[2, 2 * 10^8^]` 范围内。

 

示例 1：

**输入：**n = 6
**输出：**7

示例 2：

**输入：**n = 8
**输出：**11

示例 3：

**输入：**n = 13
**输出：**101

 

**提示：**

	- `1 <= n <= 10^8^`


## 题解


### 思路

回文数可以枚举一半然后另一半可以通过反转拼接组成回文数。
每次枚举前半段的长度为i，可以得到`2*i-1`和`2*i`长度的回文串，长度为i的数字范围$[10^{i-1}, 10^{i}-1]$，枚举每一个数`j`，在反转后得到`rj`，`j`拼接`rj[1:]`得到长度为`2*i-1`的回文串；`j`拼接`rj`得到长度为`2*i`的回文串。


### 代码


```cpp
class Solution {
public:
    bool ok(long x) {
        if (x == 1) return false;
        for (int i=2; i*i<=x; i++) {
            if (x%i==0) return false;
        }
        return true;
    }
    int primePalindrome(int n) {
        auto str = to_string(n);
        int sz = str.size();
        long b = 1;
        // cout << b << endl;
        while (1) {
            for (int i=b; i<b*10; i++) {
                long u = i, p = i/10;
                while (p) {
                    u = u*10 + p%10;
                    p /= 10;
                }
                if (u>=n && ok(u)) return u;
            }
            for (int i=b; i<b*10; i++) {
                long u = i, p = i;
                while (p) {
                    u = u*10 + p%10;
                    p /= 10;
                }
                if (u>=n && ok(u)) return u;
            }
            b*=10;
        }
        return -1;
    }
};
```
