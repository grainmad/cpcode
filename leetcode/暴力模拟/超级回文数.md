## 题目

[942. 超级回文数](https://leetcode.cn/problems/super-palindromes/)


---


如果一个正整数自身是回文数，而且它也是一个回文数的平方，那么我们称这个数为 **超级回文数** 。

现在，给你两个以字符串形式表示的正整数 left 和 right  ，统计并返回区间 `[left, right]` 中的 **超级回文数** 的数目。

 

**示例 1：**

**输入：**left = "4", right = "1000"
**输出：**4
**解释：**4、9、121 和 484 都是超级回文数。
注意 676 不是超级回文数：26 * 26 = 676 ，但是 26 不是回文数。

**示例 2：**

**输入：**left = "1", right = "2"
**输出：**1

 

**提示：**

	- `1 <= left.length, right.length <= 18`

	- `left` 和 `right` 仅由数字（0 - 9）组成。

	- `left` 和 `right` 不含前导零。

	- `left` 和 `right` 表示的整数在区间 `[1, 10^18^ - 1]` 内。

	- `left` 小于等于 `right` 。


## 题解


### 思路

枚举回文**

同2081


### 代码


```cpp
class Solution {
public:
    #define ll long long
    bool ok(ll x) {
        ll y = 0, p = x;
        while (x) {
            y = y*10+x%10;
            x /= 10;
        }
        return y == p;
    }
    int superpalindromesInRange(string left, string right) {
        ll l = stoll(left), r = stoll(right);
        int ans = 0;
        for (ll i=1; i<=1e5; i*=10) { //回文半径=5，半径为i，可得长度为2*i，2*i-1的回文串。
            // 奇数长度回文
            for (ll j=i; j<i*10; j++) {
                ll a = j, b = j/10;
                while (b) {
                    a = a*10+b%10;
                    b /= 10;
                }
                a *= a;
                if (ok(a) && l<=a && a<=r) ans++;
                if (a > r) return ans;
            }
            // 偶数长度回文
            for (ll j=i; j<i*10; j++) {
                ll a = j, b = j;
                while (b) {
                    a = a*10+b%10;
                    b /= 10;
                }
                a *= a;
                if (ok(a) && l<=a && a<=r) ans++;
                if (a > r) return ans;
            }
        }
        return ans;
    }
};
```
