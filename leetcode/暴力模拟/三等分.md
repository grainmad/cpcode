## 题目

[963. 三等分](https://leetcode.cn/problems/three-equal-parts/)


---


给定一个由 `0` 和 `1` 组成的数组 `arr` ，将数组分成  **3 个非空的部分** ，使得所有这些部分表示相同的二进制值。

如果可以做到，请返回**任何** `[i, j]`，其中 `i+1 < j`，这样一来：

	- `arr[0], arr[1], ..., arr[i]` 为第一部分；

	- `arr[i + 1], arr[i + 2], ..., arr[j - 1]` 为第二部分；

	- `arr[j], arr[j + 1], ..., arr[arr.length - 1]` 为第三部分。

	- 这三个部分所表示的二进制值相等。

如果无法做到，就返回 `[-1, -1]`。

注意，在考虑每个部分所表示的二进制时，应当将其看作一个整体。例如，`[1,1,0]` 表示十进制中的 `6`，而不会是 `3`。此外，前导零也是**被允许**的，所以 `[0,1,1]` 和 `[1,1]` 表示相同的值。

 

**示例 1：**

**输入：**arr = [1,0,1,0,1]
**输出：**[0,3]

**示例 2：**

**输入：**arr = [1,1,0,1,1]
**输出：**[-1,-1]

**示例 3:**

**输入：**arr = [1,1,0,0,1]
**输出：**[0,2]

 

**提示：**

	- `3 <= arr.length <= 3 * 10^4^`

	- `arr[i]` 是 `0` 或 `1`


## 题解


### 思路

可以分为三组说明，arr中1的个数是3的倍数。假设共有3c个1，
第c个到第c+1个之间的0，以及第2c个到第2c+1个之间的0 一定不小于第3c之后0的个数。
3c之后0的个数便是每一组末尾0的个数e。
之后只需判断每组去除前后导0是否相等即可。
最终答案是{第c个1的位置＋e，第2c个1的位置+e}


### 代码


```cpp
class Solution {
public:
    vector<int> threeEqualParts(vector<int>& arr) {
        int c = count(arr.begin(), arr.end(), 1);
        int n = arr.size();
        if (c%3) return {-1, -1};
        c/=3;
        if (c == 0) return {0, 2};
        vector<int> p;
        for (int i=0; i<n; i++) {
            if (arr[i] == 1) {
                p.push_back(i);
            }
        }
        if (p[c]-p[c-1]-1 < n-p.back()-1 || p[2*c]-p[2*c-1]-1 < n-p.back()-1) return {-1, -1};
        int l1 = p[c-1]-p[0], l2 = p[2*c-1]-p[c], l3 = p[3*c-1]-p[2*c];
        if (l1 != l2 || l2 != l3) return {-1, -1};
        int p1 = p[0], p2 = p[c], p3 = p[2*c];
        while (p1<p[c-1] && p2<p[2*c-1] && p3<p[3*c-1]) {
            if (arr[p1] != arr[p2] || arr[p2] != arr[p3]) return {-1, -1};
            p1++; p2++; p3++;
        }
        return {n-p[3*c-1]-1+p[c-1], n-p[3*c-1]+p[2*c-1]};
    }
};
```
