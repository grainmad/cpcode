## 题目

[17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)


---


给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

 

**示例 1：**

**输入：**digits = "23"
**输出：**["ad","ae","af","bd","be","bf","cd","ce","cf"]

**示例 2：**

**输入：**digits = "2"
**输出：**["a","b","c"]

 

**提示：**

	- `1 <= digits.length <= 4`

	- `digits[i]` 是范围 `['2', '9']` 的一个数字。


## 题解


### 思路

简单dfs枚举


### 代码


```cpp
class Solution {
public:
    int st[10][2] ={
        {0, 0}, {0, 0}, {0, 3}, {3, 6}, {6, 9}, {9, 12}, {12, 15}, {15, 19}, {19, 22}, {22, 26}
    };
    vector<string> ans;
    string temp;
    vector<string> letterCombinations(string digits) {
        dfs(0, digits);
        return ans;
    }
    void dfs(int pos, string& digits) {
        if (pos == digits.size()) {
            if (temp != "") ans.push_back(temp);
            return;
        }
        int x = digits[pos]-'0';
        for (int i=st[x][0]; i<st[x][1]; i++) {
            temp.push_back('a'+i);
            dfs(pos+1, digits);
            temp.pop_back();
        }
    }
};
```
