## 题目

[2171. 到达目的地的第二短时间](https://leetcode.cn/problems/second-minimum-time-to-reach-destination/)


---


城市用一个 **双向连通** 图表示，图中有 `n` 个节点，从 `1` 到 `n` 编号（包含 `1` 和 `n`）。图中的边用一个二维整数数组 `edges` 表示，其中每个 `edges[i] = [u_i_, v_i_]` 表示一条节点 `u_i_` 和节点 `v_i_` 之间的双向连通边。每组节点对由 **最多一条** 边连通，顶点不存在连接到自身的边。穿过任意一条边的时间是 `time` 分钟。

每个节点都有一个交通信号灯，每 `change` 分钟改变一次，从绿色变成红色，再由红色变成绿色，循环往复。所有信号灯都 **同时** 改变。你可以在 **任何时候** 进入某个节点，但是 **只能** 在节点 **信号灯是绿色时** 才能离开。如果信号灯是  **绿色** ，你 **不能** 在节点等待，必须离开。

**第二小的值** 是 **严格大于** 最小值的所有值中最小的值。

	- 例如，`[2, 3, 4]` 中第二小的值是 `3` ，而 `[2, 2, 4]` 中第二小的值是 `4` 。

给你 `n`、`edges`、`time` 和 `change` ，返回从节点 `1` 到节点 `n` 需要的 **第二短时间** 。

**注意：**

	- 你可以 **任意次** 穿过任意顶点，**包括** `1` 和 `n` 。

	- 你可以假设在 **启程时** ，所有信号灯刚刚变成 **绿色** 。

 

**示例 1：**

[]        []

**输入：**n = 5, edges = [[1,2],[1,3],[1,4],[3,4],[4,5]], time = 3, change = 5
**输出：**13
**解释：**
上面的左图展现了给出的城市交通图。
右图中的蓝色路径是最短时间路径。
花费的时间是：
- 从节点 1 开始，总花费时间=0
- 1 -> 4：3 分钟，总花费时间=3
- 4 -> 5：3 分钟，总花费时间=6
因此需要的最小时间是 6 分钟。

右图中的红色路径是第二短时间路径。
- 从节点 1 开始，总花费时间=0
- 1 -> 3：3 分钟，总花费时间=3
- 3 -> 4：3 分钟，总花费时间=6
- 在节点 4 等待 4 分钟，总花费时间=10
- 4 -> 5：3 分钟，总花费时间=13
因此第二短时间是 13 分钟。      

**示例 2：**

[]

**输入：**n = 2, edges = [[1,2]], time = 3, change = 2
**输出：**11
**解释：**
最短时间路径是 1 -> 2 ，总花费时间 = 3 分钟
第二短时间路径是 1 -> 2 -> 1 -> 2 ，总花费时间 = 11 分钟

 

**提示：**

	- `2 <= n <= 10^4^`

	- `n - 1 <= edges.length <= min(2 * 10^4^, n * (n - 1) / 2)`

	- `edges[i].length == 2`

	- `1 <= u_i_, v_i_ <= n`

	- `u_i_ != v_i_`

	- 不含重复边

	- 每个节点都可以从其他节点直接或者间接到达

	- `1 <= time, change <= 10^3^`


## 题解


### 思路

bfs, dijkstra**

bfs
将无向图边长视为1，求出到达n节点的最短路。
接下来模拟从1到n所需要的时间，当到达一个点为红灯时需要等待。

dijkstra
将每次移动需要的时间看作边权，但是在移动前若当前处于红灯则需要等到绿灯再移动，此时的边权需要增加等红灯的时间。
设从起点到当前点u所花费的时间为t，则t/change为奇数则处于红灯期，还需要等的时间为change - t%change


### 代码


```cpp
class Solution {
public:
    #define N 10005
    const int INF = 0x3f3f3f3f;
    vector<int> g[N];
    int secondMinimum(int n, vector<vector<int>>& edges, int time, int change) {
        int dis[n+5][2]; memset(dis, 0x3f, sizeof(dis));
        for (auto& i:edges) {
            g[i[0]].push_back(i[1]);
            g[i[1]].push_back(i[0]);
        }
        queue<pair<int,int>> que;
        que.emplace(1, 0);
        dis[1][0] = 0;
        while (que.size()) {
            auto [u, d] = que.front(); que.pop();
            d++;
            for (int i:g[u]) {
                if (dis[i][0] > d) {
                    dis[i][1] = dis[i][0];
                    dis[i][0] = d;
                    que.emplace(i, d);
                } else if (dis[i][0] < d && dis[i][1] > d) {
                    dis[i][1] = d;
                    que.emplace(i, d);
                }
            }
        }
        int rt = 0;
        for (int i=0; i<dis[n][1]; i++) {
            if (rt/change%2) {//处于红灯，需等待。
                rt += change - rt%change;
            }
            rt += time;//经过边的时间
        }
        return rt;
    }
};

class Solution {
public:
    #define N 10005
    const int INF = 0x3f3f3f3f;
    vector<int> g[N];
    int secondMinimum(int n, vector<vector<int>>& edges, int time, int change) {
        int dis[n+5][2]; memset(dis, 0x3f, sizeof(dis));
        for (auto& i:edges) {
            g[i[0]].push_back(i[1]);
            g[i[1]].push_back(i[0]);
        }
        priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> que;
        que.emplace(0, 1);
        dis[1][0] = 0;
        while (que.size()) {
            auto [d, u] = que.top(); que.pop();
            int light = d/change%2;//偶数为绿灯
            int nd = light?(d/change+1)*change:d;
            for (int i:g[u]) {
                if (dis[i][0] > nd+time) {
                    dis[i][1] = dis[i][0];
                    dis[i][0] = nd+time;
                    que.emplace(nd+time, i);
                } else if (dis[i][0] < nd+time && dis[i][1] > nd+time) {
                    dis[i][1] = nd+time;
                    que.emplace(nd+time, i);
                }
            }
        }
        return dis[n][1];
    }
};
```
