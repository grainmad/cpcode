## 题目

[2. 两数相加](https://leetcode.cn/problems/add-two-numbers/)


---


给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

 

示例 1：

[]

**输入：**l1 = [2,4,3], l2 = [5,6,4]
**输出：**[7,0,8]
**解释：**342 + 465 = 807.

示例 2：

**输入：**l1 = [0], l2 = [0]
**输出：**[0]

示例 3：

**输入：**l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
**输出：**[8,9,9,9,0,0,0,1]

 

**提示：**

	- 每个链表中的节点数在范围 `[1, 100]` 内

	- `0 <= Node.val <= 9`

	- 题目数据保证列表表示的数字不含前导零


## 题解


### 思路

建立空头链表rt，最后返回rt->next即可。
指针u始终指向rt最后一个节点。
同时遍历l1和l2，为rt新增节点。当有一个链表遍历完毕后，再将另一个链表剩余部分遍历完即可。
最后注意加法进位是否还需要新建一个节点。


### 代码


```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode* rt = new ListNode(), *u = rt;
        int add = 0;
        while (l1 && l2) {
            u->next = new ListNode((l1->val+l2->val+add)%10);
            add = (l1->val+l2->val+add)/10;
            u = u->next;
            l1 = l1->next;
            l2 = l2->next;
        }
        while (l1) {
            u->next = new ListNode((l1->val+add)%10);
            add = (l1->val+add)/10;
            u = u->next;
            l1 = l1->next;
        }
        while (l2) {
            u->next = new ListNode((l2->val+add)%10);
            add = (l2->val+add)/10;
            u = u->next;
            l2 = l2->next;
        }
        if (add) {
            u->next = new ListNode(add);
        }
        return rt->next;
    }
};
```
